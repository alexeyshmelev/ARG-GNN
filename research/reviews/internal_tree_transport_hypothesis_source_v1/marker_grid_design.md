**Question.** Given identical complete-tree emissions and bin-local SNP evidence, does using a complete-tree state to set ancestry persistence improve accuracy and tract transitions beyond using the same learned graph signal for local confidence calibration in a fixed distance-only chain? This is one placement-of-information comparison. It is narrower than testing all graph-conditioned transition families.

**Common emissions and geometry.** Warm-start the complete H042 pass30 body, train every weight, and retain both full PyG sweeps, all952 haplotypes and the full genomic BiGRU. At each original scored center x_b and query q, take base logits l_bq and the width32 second-sweep whole-tree leaf context c_hq from the containing native hold. Every original tree/vertex remains a body input.

Assign each callable SNP to exactly one original half-open physical scoring bin. In this new channel, form four centered reference-only categorical compatibility means and log1p(call_count), using the H044 categorical/allele-cardinality tables and H046 common-callability rule: a site requires a called query and at least one called reference in every source class. Sites missing a reference class give no new-channel evidence. Evidence is zero when no valid site is present. An 84-parameter 5→8 GELU→4 head, with final layer initially zero, gives marker emissions m_bq. Multiply that head by the valid-bin mask so a missing bin adds zero marker evidence. The common emission is e_bq=l_bq+m_bq. No overlapping 1-kb windows, deterministic contrast gate, bounded final-logit correction, ancestry-derived coordinate or auxiliary target is introduced. This is a conditional feature model, not an assertion that correlated SNPs are independent calibrated likelihoods.

At edge b between adjacent original centers, let delta_b=x_(b+1)-x_b>0 bp. Form s_bq=[(c_left+c_right)/2, |c_right-c_left|], dimension64. A 64→16 tanh→1 head F has 1,057 parameters, and g_bq=2*tanh(F(s_bq)). Its final weight/bias initially zero. Inside one native hold, this input is constant, so compute the head once for each distinct ordered pair of containing holds and gather its scalar output. A monotone center sequence has at most 2T-1 such pairs. The chain may switch at every scored-bin edge, including edges strictly inside a native hold.

**Constrained generator with a cheap exact transition.** Learn one global base rate lambda0 between 1e-6 and 1e-3 bp^-1, initialized at1/50000 bp^-1, and one global destination simplex pi=softmax(beta1,beta2,beta3,0), initially uniform. These are concrete design defaults, not tuned biological findings. Define the row generator

    Q_bq = lambda_bq * (1*pi^T - I).
    P_bq = exp(delta_b*Q_bq)
          = r_bq*I + (1-r_bq)*1*pi^T,
    r_bq = exp(-lambda_bq*delta_b).

Off-diagonal rates are nonnegative, rows sum to zero, P preserves probability and admits multiple latent resets over a gap. Actual exit rate from class a is lambda*(1-pi_a), so lambda is a reset rate, not the observable class-switch rate. No 4×4 matrix exponential or adaptive ODE solver is needed. Compute log(1-r) from -expm1(-lambda*delta) and diagonal log probabilities by logaddexp, without a probability floor. This reset-generator restriction is deliberate. It does not represent arbitrary directed class-to-class transition preferences.

The two arms have the same 31,933 total parameters (30,788 body +84 marker +1,057 conditioner +4 rate/simplex), identical initialization and independent reset AdamW:

- **Graph-to-transition:** lambda_bq=lambda0*exp(g_bq), with e=l+m.
- **Graph-to-own-confidence:** lambda_bq=lambda0 everywhere, with e=exp(gbar_bq)*l+m, where gbar is the mean of existing incident-edge g values, using the single incident edge at an endpoint. Thus every conditioner parameter remains connected to a local own-state confidence path instead of silently becoming inactive in the fixed-rate arm.

At initialization g=0, both models have identical emissions, transitions and chain outputs. Both have the same observed graph/SNP information and small-head capacity. Full forward-backward marginal probabilities are trained with the unchanged original-grid exact-span loss. Use initial prior pi. Graph-to-transition changes actual pair coupling, not a bounded output tweak. The control still uses graph evidence in its emissions. A gain therefore supports persistence conditioning over this matched local-confidence use, not graph usefulness in general or arbitrary neural-rate expressiveness.

**Realistic execution costs, not a fit certificate.** Let P<=20,000 centers, Q=686 queries, H=952, T native holds, N total native vertices and S observed SNPs. Complete PyG/site/BiGRU work is unchanged. Bin preparation costs O(S*Q*4) once per observed parent and must be streamed. Grid emission work costs O(P*Q*72) multiply-accumulates. The conditioner costs O(min(P-1,2T-1)*Q*1040) multiply-accumulates. At T=938 (a previously reported H046 parent count, not inspected here), this is about1.34 billion conditioner MACs and0.99 billion marker-head MACs at maximum P. Those operations are not free merely because parameter count is small.

A sequential forward-backward recurrence is O(P*Q*4), but a Python/CUDA loop over20,000 positions is unacceptable. Reuse the balanced log-semiring4×4 scan structure already present in H039, with query blocks32 and checkpointed full-length scans. Its arithmetic is O(P*Q*4^3), not the ideal scalar-sequential count. Whole-chain gradients must cross every position. Block queries only, preserving complete tree and genomic-history gradients.

At maximum P, one FP32 probability tensor is219.52 MB. CPU bin features5×P×Q are274.4 MB before masks and other observations. One query-block4×4 matrix table is40.96 MB, and its explicit4-way log-product broadcast is163.84 MB. Scan outputs/reductions/recomputation/autograd add more. Avoid the1.756 GB all-query width32 grid-context expansion by gathering only compact hold-pair contexts and per-block scalars/logits. These are named-table sizes, not peak-memory bounds. Checkpointing query blocks keeps large scan tables from being saved for all686 queries, at additional arithmetic cost. Save full raw marginal outputs only under the existing prediction/checkpoint policy. No timing improvement over H046 or fit within a GPU cap is established. The first genuine scheduled TRAIN update, if separately authorized, must qualify peak allocator use and wall time without extra disposable optimization.

**Prior art and interpretation.** [RFMix, Theory/LAI](https://pmc.ncbi.nlm.nih.gov/articles/PMC3738819/) already combines reference-based emissions, distance-aware transition potentials and linear-chain CRF inference. [FLARE](https://doi.org/10.1016/j.ajhg.2022.12.010) already uses an extended Li–Stephens ancestry model. H039 is the closest project-level precedent. [Neural Continuous-Time Markov Models](https://arxiv.org/html/2212.05378v1), abstract and methods, already learn rate functions depending nonlinearly on external covariates. [Neural ODEs](https://arxiv.org/html/1806.07366v5) already parameterizes continuous dynamics by neural networks, although this design uses a closed-form finite-state transition and is not an application of its adaptive solver. No new HMM, CRF, neural ODE, CTMC or general GNN operator is claimed.

The distinguishable untested task hypothesis is that a fully learned whole-tree representation can place context-dependent persistence on a marker-resolution ancestry chain better than the same representation used for local confidence alone. The exact combination's publication priority remains unverified. The genealogical state is observed evidence, not an identified ancestor or source-population state. The generator is a conditional regularizer given the observed graph, not a recovered recombination process or admixture age. Ancestry switches need not coincide with tree changes. Physical bp are used explicitly, because this frozen simulation setting has constant recombination; extension to heterogeneous real maps would require observed genetic distances and renewed validation.
