# H018: inferred graph plus original SNP observations

**Conclusion.** Lossless genotype export from the inferred tree sequence is not a necessary prerequisite for using an inferred genealogy as a statistical graph feature. A separately registered, explicitly graph-only view of the immutable H018 .trees container, paired with the immutable original 2,074-site SNP observations, is scientifically defensible. It matches the separation of graph and SNP provenance in the TRAIN pipeline. It does not make the original lossless-export gate pass, prove the genealogy biologically correct, or authorize current model application.

**What failed remains failed.** All eight native stages returned 0, while the controller genuinely returned 1 and produced no completion. Root reports that 355 marginal trees, 27,690 edges, all 40 tips, dates, support and exact correspondence to native .anc passed. The independent compact diagnosis records 198/2,074 sites and 692/82,960 nucleotide calls differing in the exported mutation representation, with all 277 constants correct. The native .mut interpretation itself differs at 180 sites by one call each. The converter also mishandles flipped/multibranch representation. The source permits a one-call approximate clade match at N=40. Therefore this is not solely a serialization bug. Perfect topology correspondence and perfect sequence reconstruction are distinct properties.

**The TRAIN genotype provenance is separate.** The frozen original input points to the v5 observed cache with 40 TRAIN/VAL entries and pinned producer/loader sources. Source inspection establishes this chain:

| Stage | Evidence |
|---|---|
| Tree extraction | full_panel_observations lines 156–162 load native .trees, join sample identities/times, extract holds and delete the TS object. |
| Original SNP source | Lines 163–183 parse the separately pinned observed VCF and return alleles.genotypes, allele cardinality and original positions. observed_variant_residual lines 60–128 check REF/ALT, phase, missingness, site identity and coordinates. |
| Mutation independence of extraction | parent_loader lines 176–228 consult only sampled nodes, parents, times and intervals, explicitly excluding mutation/population/ancestral-allele tables. |
| Feature construction/cache | tree_observations lines 475–518 use that original matrix for site-to-hold assignment, branch concordance and donor frequencies. v4/v5 producers pass observed.genotype into the cached model arrays. |
| H044/H046 | H044 preparation compares the original-loaded genotype with the bank genotype, then marker evidence borrows that exact bank tensor. H046 wraps this bound bank plus topology/interval clade arrays. |

The branch-support calculation explicitly allows closest-clade discrepancy as well as exact splits. It is not a requirement that every observed allele map perfectly to one inferred branch. Mutation tables are not the source of the observed SNP features. This is provenance independence, not statistical independence: the inferred genealogy was estimated from those same observations.

**Conditions for a new contract.** Keep the existing native files and their mutation tables unchanged. Use a read-only graph accessor restricted to samples, nodes, edges, intervals and times. Declare the original SNP source authoritative for every genotype feature and prohibit ts.variants/genotype_matrix, inferred ancestral states and .mut placements from supplying or correcting observed calls. Retain all 2,074 sites, including 277 constants and every discordant polymorphic site, with exact biological allele dictionary, phase, missingness, sample identity and original physical coordinates. Do not “repair” the mutation tables or filter to concordant sites.

The original bridge's frozen HAPS/nucleotide-equivalence bindings can support that separate feature provenance; this assessment has not reopened the underlying empirical vectors. A downstream contract still needs its own exact feature-equality and consumer-source evidence.

Coordinates are substantive: H018 native positions map to regional bp0 by subtracting 1, then to absolute bp0 by adding 20,000,000. Only the already declared first-SNP through last-SNP+1 supported span is usable. Raw left-flank table coverage is not evidence for flanking genealogy or full 10 Mb coverage. This is an explicit logical observation domain, without rewriting the artifact.

**Biological objections and limits.** Inferred genealogies are approximations. Genotyping/phasing error, recurrent changes and inference approximations can make observed allele patterns incompatible with a single clade. Preserving the original observations alongside the estimate is legitimate and avoids silently replacing them with clade-smoothed calls. However, the mismatch pattern is not a random measurement-error guarantee. These facts do not identify which biological or inferential cause explains a site, or show that inferred topology/times are unbiased. Support and times were inferred using the same SNPs, so they are correlated derived features, not independent evidence to multiply into a likelihood.

There is also a separate deployment problem: H042/H046 production paths require 952/686 haplotypes/queries, synthetic 2 Mb coordinates and their registered preparation. H018 has 40/R16/Q24, a regional empirical marker set and fixed-N pre-size inference, whereas the TRAIN lineage uses post-size inferred trees. Marker density/ascertainment, reference uncertainty, sample/error profiles and branch-time calibration can all shift predictions. The graph-plus-original-SNP design does not establish compatibility, calibrated uncertainty or ancestry accuracy in that domain.

**Recommendation.** Permit scientific consideration of a new graph-plus-original-observation contract with its own registration and scope. Preserve the failed original gate, controller wait1, null completion, full charge and discrepancy record. Qualification of graph extraction, original SNP fidelity and any adapted downstream consumer must remain separate. No native rerun, filtering, genotype reattachment, mutation/time/tree edit, model application or retrospective promotion is recommended here.

Exact source references, line locators, compact facts and inactive contract conditions are recorded in facts_and_provenance.json and proposed_contract.json. Only source and existing small summary metadata were read. No full native/vector facts, raw empirical/TRAIN SNPs, ancestry targets, model/checkpoint, GPU/process, guard/admission or Git operation was used.
