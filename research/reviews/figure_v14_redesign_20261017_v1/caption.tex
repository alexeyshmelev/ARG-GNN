\caption{(a) A recorded toy ancestral recombination graph and its three exact marginal trees. Translucent planes mark genomic intervals, black continuities join the same lineage, and $t$ denotes time. Tip colors identify references (Ana, CHG, WHG, EHG). The outlined query $q$ has a zero four-source ancestry vector and a separate unknown mask. Examples show observed alleles and node age $\tau$, root status and sampled status. (b) The site MLP is pooled before the leaf MLP, which also receives reference information and sample age. The node MLP supplies the additive base $b$. Arrows proceed right to left. The same complete upward/downward GNN, parameterized by $\theta$, is applied twice. First-application states supply a local structural residual and memory correction, both added to $b$ before the second application. Linear--tanh readout gives an aligned embedding sequence $e$ per sample. (c) The dashed 350-generation cut and highlighted representative use the same first tree. Linear $U$ maps its upward-plus-outside state to forcing $f$, copied to its sampled descendants. Fixed sample rows persist as tree groups change. Forward/reverse exponential moving averages (EMA) use physical interval width $\Delta x$. Averaging both directions and the current group, subtracting $f$, then applying Linear $O$ returns the representative correction $\delta$. (d) Embeddings and interval geometry enter a one-layer BiGRU for every sample. Its output is concatenated with local $e$ before the inherited MLP and softmax. Only the displayed output selects $q$. Probability bars and the chromosome mosaic are illustrative, not fitted predictions. Vector strips abbreviate dimensions; full observed frequency, callability and geometry encodings are defined in Methods.}
