# Full-panel native supervised preparation v1

Implementation handoff, 2026-10-11. All writes are inside this repository on anogena. No actual parent target array was opened, no full feature bank/native archive was prepared, no model was created or fitted, and no GPU job/install/Git operation was performed. The user's 1 TB storage allowance remains root-owned. This bridge does not implement or alter storage-budget sources.

## Root integration API

Import arggnn.prepare_full_panel_native_supervised_v1. Its CLI is read-only and defaults to policy/source validation without any parent access. Mutating APIs require an explicit root write-guard callable and CUDA_VISIBLE_DEVICES="". Output directories are created exclusively and no existing artifacts are overwritten.

1. read_completed_parent(parent_id, inference_record, completion_record, *, config_path=CONFIG, split_path=SPLIT, require_argmix_native_ids=False) reads bound completion/inference receipts and observations only. Records contain repository-relative path and exact sha256. Completion uses data/ancestralpaths_full_panel_discovery_v1/<parent>/all_completion.json or separately completed relate_completion.json. It returns an in-memory mapping with ts, rows, validated roster, support, complete site_join, local/original site positions, original input bindings, source receipts and frozen protocol. observed_summary(observation) returns a JSON-safe compact summary. No truth binding is included in the observation frame.

2. prepare_observed_frame(observation, output_dir, *, guard) writes references.tsv, native_sample.sample, local_uniform_map.tsv, observed_roster.json, observed_coordinates.npz, and frame.json. It returns the frame mapping plus its bound manifest record. The stock ARGMix node-ID rule is explicitly required here.

3. prepare_ap_features(observation, output_dir, *, guard) writes <parent>.npz, <parent>.json, and features.json. Its NPZ stores features[unique_native_signature,5,9], complete grid_feature_index[retained_centers,686] and site_feature_index[retained_sites,686], original coordinates, clipped edges, retained grid indexes, actual query node IDs and genotype sample slots. The return mapping has feature_cache, feature_metadata, and manifest records. It supports actual noncontiguous node IDs. Before the reused optimized cache it verifies that observed sample nodes are terminal. A future inferred ARG violating that assumption fails and requires a separately reviewed feature adapter.

4. prepare_ap_training(observation, feature_record, truth_record, output_dir, *, guard) takes **the bound features.json manifest record**, not the raw NPZ record. It verifies cache/tree/inference/coordinates before opening the explicit bound <parent>/truth/full_truth_intervals.npz. Only downstream TRAIN000/001 are allowed. It writes training_rows.npz with features, native_labels_0based, and native_targets_onehot6, plus the exact frozen sampler's <parent>_training_selection.npz, <parent>_sampler.json, and training.json. The return mapping includes all records and realized/shortfall counts.

5. prepare_argmix_targets(observation, truth_record, output_dir, *, guard) allows only TRAIN000/001 gradients and INTERNAL_VAL002 native selection. It writes <parent>.native_truth.npz with stock variant_pos (local integer bp0), truth__hap_labels[site,686], truth__sample_ids[343], and ancestry_names (Ana,CHG,WHG,EHG), plus targets.json. It never emits donor census targets.

6. prepare_argmix_archives(frames, targets, output_dir, *, guard, admitted_cli_record, native_modules, archive_write_upper_bound_bytes) requires mappings containing exactly TRAIN000, TRAIN001 and INTERNAL_VAL002. Pass returned bound frame and target bundles, independently admitted stock CLI record, and root-qualified (torch, ancpath, joint, trainer, loader) modules from the ABI210/cu129 Python3.12 environment. Root provides positive native write upper bounds for train and val and the guard checks them before bulk Rust writes. It writes native pair YAMLs, unchanged native backend settings, uniform map, stock train.pt/val.pt, logs/commands and native_prepared.json. The backend includes the independently verified TRAIN000 reference metadata pointer for stock startup counting/logging. Archive shape/vocabulary/class labels/map channels are validated by the author loader. No optimizer is invoked.

The raw truth record must match the producer's generation receipt. Query identities must match the observation's source_observed_node_id order. Target stages read external query interval arrays and never a census-annotated tree.

## Scientific fidelity

The reader preserves all 952 haplotypes, 686 queries including BAA, 266 source donors with unequal C4 sizes, and all 34 donors older than census350. Older donors remain observed source-deme prototypes and never receive fictitious census descendants. Original genotype slots, actual inferred node IDs, diploid identity, age template, nine observed input hashes, primary tree hash, five-iteration receipt, exact conversion site map and coverage are verified.

AP uses the unchanged native feature bridge and reuses the pinned v1 optimized cache through a single AST cardinality replacement: its ObservedPanel diploid-order range changes from280 to952. Shell traversal/arithmetic/signature deduplication, present exclusion, ancient focal inclusion, integer ages, five informative shells and -15 padding retain the original algorithm. The exact pinned v2 sample_realized_source_rows function is called unchanged. Its /3 overhead, original cohort traversal, class caps, float step += step/2, replacement duplicates and bounded128-pass/no-progress shortfall policy remain. Two TRAIN parents request325,000 rows at most. AP targets and outputs remain six-class. C4 collapse is (p1+p5,p2+p6,p3,p4) and never replaces the native AP endpoint.

ARGMix metadata contains QUERY for every query, C4 ancestry tokens only for the266 donors, and actual age for every sample. The author vocabulary sorts tokens independently from the declared class remap. It reuses the unchanged release/execution copy, Rust builder and existing backend stage logic, retaining fast extraction, first-SNP supervision, TRAIN/VAL edge exclusion, no merging,16→drop1 TRAIN references versus15 VAL/inference, native log2/cap14 TMRCA, width128/4-layer4-head Transformer and bidirectional GRU128, chunks1024/stride512, two stored map channels and raw-span single active channel. The objective, smoothing0.1, unweighted masked VAL batch-mean loss, patience2 and lowest-loss checkpoint restore are unchanged. Source seed50 remains root's fitting responsibility. Current-release native components, C4 task adaptation and split remain explicitly distinct from unavailable exact published configurations.

Outer target use is rejected by every supervised preparation API before file access. Observed inference/transductive consumers may use the strict reader later under root admission, but no outer data was read in this implementation task.
