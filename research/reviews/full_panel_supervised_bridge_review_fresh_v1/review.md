The trust model is a root-bound observation/target bundle and independently qualified native modules, with a callable root write guard and empty CUDA visibility. It is not an OS sandbox against a caller that fabricates new manifests, hashes, or callbacks. The CLI is read-only; the policy's execution flags are false. Root must supply actual observation/runtime/budget admission before importing and invoking mutating APIs, and must freeze/verify future prediction and selection seals before external scoring.

The unchanged Rust training builder (build_training.rs:745-755) stops after the first chunk that reaches the end (>=), whereas the unchanged streamed inference routine (joint_interval_model.py:1577-1595,1647-1669) can flush an overlapping partial chunk even after an exact-end full chunk. The current bridge correctly leaves this source distinction intact. Label the trailing-overlap claim as streamed inference behavior; do not modify archive chunking to make it match that claim. 2. **Evidence limitation — Handmade topology is simple.** The current harness's two star trees test all 686 queries, noncontiguous IDs, group arithmetic, age conversion, one informative shell and root padding, and compare every handmade site/center to the direct bridge. They do not exercise five distinct informative shells, skipped empty intermediate ancestors or complex nested signatures. The source logic supports these cases, but the 10-check receipt must not be cited as empirical qualification of every topology or actual full-panel memory. A small branching/multilevel synthetic example would improve regression evidence when extending this optimized algorithm; this audit found no current mismatch requiring a source change.
