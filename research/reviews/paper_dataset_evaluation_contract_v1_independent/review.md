# Independent audit of paper-dataset contract v1

Verdict: **BLOCKED, source-contract only**. The source pins and metadata are consistent, but three known native conditions need explicit disclosure in a separate versioned amendment. This audit preserves v1 unchanged and makes no empirical qualification.

- **I1 / P1 — BH normalization scope.** `eval_react.py:1531` fits target statistics to the whole 70% pool before fraction-specific subset and validation selection at lines 1593–1600. Small-fraction runs therefore use target labels outside TRAIN, including VAL labels. Preserve this as the released-source condition and mark any TRAIN-only statistics variant as changed.
- **I2 / P1 — GST learning rates.** Paper §3.1.2 specifies AdamW learning rates 1e-3 for DeepSets/SetTransformer and 1e-4 for GST. All three cached source configurations use shared `args.lr=0.001`; the corresponding runner optimizers consume it for every model. v1 discloses the BH optimizer discrepancy but omits this known rate discrepancy.
- **I3 / P2 — AP original GNOMix comparison.** Supplement Note 3, printed p34, uses EHG/WHG/CHG/Ana references and GBR/Bronze Age/Neo/Yam queries, excludes BAA, scores evenly spaced sites from five 200 Mb sequences, and uses the genuine GNOMix logistic-regression base plus xgboost smoother, 0.02 cM windows for GBR and 0.2 cM for the other cohorts. Bind this published endpoint and leave unavailable version/seed/split identities unknown. A summed six-path output is not this native comparison.
- **I4 / P2, nonblocking — validation draw uniqueness.** The synthetic runner generates 640 fresh validation draws across five checks. It does not prove 640 byte-unique datasets. Use “generated draws” or explicitly define “distinct” in terms of generator consumption.
