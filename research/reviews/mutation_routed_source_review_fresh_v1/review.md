# Independent H036 source and biology audit

Reviewed prospectively from the registered standalone experiment, its four principal sources and author receipts. No requested verdict was supplied. This audit read source and JSON receipts on anogena only. It did not open actual genotype, native-tree or ancestry-target arrays, execute training, launch a GPU, install packages or perform Git actions. The root's integration receipt was also encountered during provenance reading; its verdict was not adopted as evidence of correctness. The user's 1 TB storage instruction supersedes the older 500 GB text in AGENTS.md. Storage and GPU admission were outside this scientific audit.

## Assessment

No source-level scientific blocker to the bounded H036 developmental pilot was found. The implemented observation bank, full-parent recurrence and exact-span supervised loss are consistent with the main registered design. This is a conditional source assessment, not validation of actual parent payloads, real full-parent gradients, memory/runtime, predictive utility, generalization or priority.

### Target leakage and observed joins

The loader accepts the four original development parents and an exact observation-reference schema. ObservationOnlyParentReaderV1 blocks known truth/oracle/census/target paths and verifies content hashes. The preparation pipeline loads original VCF, observed rosters, inference tree, and coordinate contracts. It neither receives target bindings nor uses inferred population, mutation-table or ancestral-allele annotations for features. Whitelisting and path checks are useful boundaries, not proof by themselves that an upstream inference artifact has no latent contamination. The pinned qualified inference lineage and its upstream observation-only construction remain the provenance premise.

The roster join requires unique (sample_id, haplotype) identities, exact original/derived rows, an explicit sample-index-to-native-node bijection and native sample dates. All 280 haplotypes survive, with pure reference96 (24 per source), mixed reference64 and query120. Only pure-source proxies receive observed C4 labels. All queries and mixed references have unknown input ancestry. The VCF parser requires the original diploid sample header order and phased pairs, checks each site against the explicit 0-based/VCF+1 coordinate manifest, retains all original variants including multiallelic sites, and encodes missing calls as -1. Consequently the loader's direct use of parser columns follows a verified identity order rather than an unverified positional guess.

The full genotype panel contributes observed frequencies and clade support, which is transductive use of the observed query genotypes, not access to query ancestry. Reference self-membership in allele-frequency features is shared by both arms and does not create query-target leakage. Sample age and reference labels are inputs, while cohort/query roles are used for roster selection and scoring rather than a network cohort feature. Internal node identities are lookup keys only.

The native sampled-ancestor union retains unary vertices and every original marginal interval. It checks raw float64 chronology before casting to FP32, with raw-derived positive durations allowing rounded FP32 clock ties. Sites and readout centers are assigned to their containing half-open physical intervals with the same explicit coverage offset. Original fixed100 bp centers and clipped bin edges are preserved for scoring. Genuine coverage tails without scoring centers still enter recurrence. Source inspection supports these contracts; actual payload conformance remains unverified by this reviewer.

### Full-parent recurrence and supervision

The model constructs site/leaf features and two cavity sweeps over the complete forest, then executes one bidirectional GRU on [native hold, persistent haplotype, feature]. There are no artificial tile resets or detached genomic histories in the code. The downward cavity subtracts the receiving child's upward contribution and introduces the child's own representation only in the final leaf readout.

Training performs one optimizer update for each complete biological parent, using every retained query readout and the unchanged exact class-span loss. There are two TRAIN parents and10epochs, hence20updates per arm. All120queries supply TRAIN supervision, with Present64 used for checkpoint selection. The exactness is the integration of C4 truth mass over the original100 bp scoring bins: predictions are gathered from the native hold containing each bin center. It does not imply distinct predictions for every true breakpoint inside a scoring bin or an exact continuous genomic likelihood. Holds without scoring centers can influence supervised holds through the undetached GRU.

All four observation banks are durably receipted before TRAIN targets open. Within each evaluation phase, both VAL probability files are sealed before either VAL truth is scored. VAL NLL nevertheless selects checkpoints over the same two reused development parents, so sealing prevents direct truth access during prediction but does not turn these VAL parents into independent TEST data.

### Six-to-four biological meaning

The external target helper decodes only source_classes_0based, interval boundaries and original query identities. It does not decode native_paths_1based. The upstream source generator uses PATH_TO_CLASS=(0,1,2,3,0,1): native paths1/5 are Ana,2/6 CHG,3 WHG and4 EHG. The additional paths5/6 are BAA routes to the same census source populations. Census labels are taken at generation350, after the specified backward admixture events and before the four source populations merge. This collapse is biologically coherent for this synthetic four-source estimand. It deliberately discards route identity and does not establish a general rule for six arbitrary human ancestry labels. Observed source proxies are treated as pure by the synthetic sampling design, not as a universal purity property of historical reference groups.

### Controls and interpretation concerns

1. **Registered sham qualification requires manual reconciliation.** shuffle_branch_support_v1 preserves the whole-vector multiset within each tree and frozen TRAIN-derived duration/descendant bins, with seed101 and no favorable reseeding. However its mechanism_inconclusive flag tests supported_vector_moved_fraction<0.5. Registration says fewer thanhalf supported fields move or support has no meaningful variation. Vector movement and field movement are different, and the flag does not test a minimum amount of support variation. The preparation receipt does supply per-field movement counts, physical/readout-weighted fractions and constant-field names. Actual parent receipts must be evaluated against the registered rule before a placement-mechanism claim. The handmade receipt illustrates the difference:0.9333 of supported vectors changed while0.4026 of all nonzero support fields changed, partly because callable_split_count and empty are constant within a tree. Root acknowledged this concern and will inspect actual movement and variation without altering bins or prespecified margins. This is an interpretation gate, not a blocker to obtaining the registered observations.

2. **Only the paired sham is an architecture/input-matched control.** The aligned and shuffled models have identical observed SNPs, topology, ages, roster, dimensions, initialization scheme, optimizer and update schedule, with branch-support placement as the designated difference. Their initialization hashes and actual preparation receipts should match. Historical ordinary smoothing uses different original-genotype inputs and Relate rather than the tsinfer/tsdate topology. An advantage over it is a pipeline comparison, not isolated evidence that support routing caused improvement. This limitation is already explicit in config/registration and must remain explicit in results. Matching ten full-parent epochs to historical genome exposure does not match optimizer-step count, optimization path or effective compute.

3. **Concordance is not independent mutation evidence.** The branch summaries compare observed allele splits with descendant sets of an inferred tree built from the same observed SNPs. This is a coherent observation-derived inductive bias and is not ancestry-label leakage. It does not measure independent mutations, true mutation positions, polarization, mutational rates or a separately observed genealogy. Symmetric discrepancy counts both biallelic complements, handles multiallelic splits, and shares ties across unary branches. Mechanistic wording should remain observed allele-clade concordance routing.

4. **The pilot cannot settle superiority or novelty.** Two TRAIN and two previously reused VAL parents, no TEST parent, one seed, and checkpoint selection on development NLL support only a developmental effect-direction observation. The registered+0.2percentage-point margin and positive direction on each VAL parent are useful discovery gates, not a statistical significance test. A budget continuation adds optimization exposure and must be registered before further updates as already required. Tree supervision, cavity messaging, gates, allele/genealogy fusion and genomic recurrence are established ingredients. The narrow candidate contribution is the observed support-placement mechanism, with priority and predictive benefit unresolved.

No novel numerical check was needed for this source audit. No actual result is asserted.
