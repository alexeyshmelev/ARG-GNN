## Biology and role eligibility verified against author source

The author simulator assigns source demes EHG=3, WHG=4, CHG=7, Ana=8, with no migration and no admixture affecting these demes. It samples WHG/EHG/Ana/CHG directly, before their backward splits at 600/800 generations. Admixture applies to present/Bronze, Neo, Yam and BAA. In training.py:73–90, census350 population8 gives non-BAA path1 and BAA path5; population7 gives path2/path6; population4 gives path3; population3 gives path4. Supplementary Note3's FigS7 caption says path5 starts in BAA and joins path1, while path6 joins path2. Thus:

| Response | Source component | Route distinction |
|---|---|---|
| paths1/5 | Ana | European/Neo route versus BAA route |
| paths2/6 | CHG | European/Yam route versus BAA route |
| path3 | WHG | Neo route |
| path4 | EHG | Yam route |

The correct C4 distribution, in Ana,CHG,WHG,EHG order, is **(p1+p5,p2+p6,p3,p4)** before argmax. This discards path history while preserving the terminal source component. It is not the paper's separately retrained BAA-excluded four-path model.

Retain all 952 observed haplotypes: queries 0..685, pure-source donor roles 686..951. Donors are WHG102/EHG86/Ana50/CHG28 haplotypes, unequal class sizes. Their observed age ranges are WHG210–529, EHG155–402, Ana217–360 and CHG184–473. All remain in their unadmixed source deme at sampling. There are 34 donors older than350 (12/10/2/10 respectively): these are source-deme prototypes, not samples with a later census350 ancestor to label. Do not discard them or infer reference purity from query truth. BAA14 haplotypes are admixed queries, never pure donors. Other query roles carry null reference class. These statements are specific to the simulated source demography, not empirical proof of real-world population purity.

## Predictions, scoring and checkpoint reuse

All methods seal both outer parents' predictions, IDs, coordinates, checkpoints and class order before any outer truth capability. Common C4 scores use exactly matched observation-defined support and clipped bin intersections, equal-parent query-bp accuracy/NLL, present182 separately, each ancient cohort and all686. Report excluded tails, method missing mass/failures and denominator coverage. Never erase a native support gap by restricting to successful rows; a complete-support metric is unavailable when required predictions are missing. Any extra intersection-only diagnostic must declare its denominator. Infinite raw vote NLL is flagged with affected positive query-bp, without a floor. Native six-path row metrics stay distinct from physical C4 metrics.

Existing reduced-panel Dense and trained C4 ARGMix weights are technically reusable after a new input adapter as separately labeled frozen cross-panel transfer controls, if exact feature/vocabulary/head identities pass. They cannot stand in for the new full-panel fitted competitors. Main comparison therefore retrains Dense/ARGMix on TRAIN000/001, using002 only where native selection requires it. No existing ARGformer checkpoint can directly score these new ARGs: numerical node IDs do not transfer semantic vocabulary identity. Fit each scored parent's observed-only namespace anew and report transductive fitting cost separately from inductive inference.
