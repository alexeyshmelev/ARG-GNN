## Paper and release findings

Four material conflicts remain visible, with source-backed inactive remedies:

| Detail | Paper | Executed release |
| --- | --- | --- |
| Contrastive temperature | Default 0.05 | YAML overrides the code fallback to 0.30 |
| Class weights | Inverse class frequency, normalized over valid anchors | Formula exists, but model builder receives cfg.model and cannot see root train_loader. A caught exception selects uniform weights |
| MLM corruption | Every selected node becomes MASK | Active loader uses the Hugging Face default corruption. The inherited utility and its test state 80/10/10. Training selection is 0.30 and validation selection is 0.15 |
| MLM extant representation | Figure 2 describes extant-node pooling | Released input removes the leaf. Position 1 is the first ancestor, correctly named first_node in current documentation |

The supervised in-batch loss otherwise has the paper structure: all nonself examples enter the denominator, all same-class partners are positives, and anchors without positives are excluded. The pair dataset and explicit-negative collator are unused. YAML hard-negative count, negative-sampling temperature and symmetric settings do not alter the selected runtime route. Enabling those unused alternatives would be a new algorithmic change, not a recovered paper implementation.

Full raw leaf-to-root paths are deduplicated before truncation. The seed-42 pretraining split is 90/10 over unique paths within one ARG vocabulary. It is not an independent subject or independent ARG holdout. At sequence length 128, leaf skipping retains at most 126 ancestors plus the two special tokens. Distinct full paths may have identical model inputs, so neither truncated token IDs nor embedding values are valid raw-path identifiers.

The active contrastive embedding is the learned pooling head followed by L2 normalization. Its mean operation averages over the sequence dimension without an attention mask. The separate export option named mean masks padding and is a different representation. The maintained wrapper correctly uses head_norm, exports one ordered split at a time with no sample cap, and preserves complete raw-path order sidecars. It verifies every encoder tensor transferred from the MLM checkpoint and requires live and saved full-budget optimizer counters. Checkpoint loading and the maximum in-batch metric logger do not recover an original paper checkpoint selection rule.

The current MLM CLI is complete, but the public contrastive CLI still requests absent yamls/defaults.yaml. The maintained adapter bypasses only that operational gap by loading the released YAML and calling unchanged train(cfg). It explicitly requires the release temperature and uniform weighting fallback. It changes paths, disabled logging/autoresume, device binding and finite checkpoint retention, and adds a final full-budget checkpoint. These are disclosed operational adaptations. Several inherited smoke tests reference absent modules or YAMLs and cannot certify Table 1. None was run here.

## Original-study details and our explicit choices

Paper-known American parameters are resolved: 30 Mb, the catalog AmericanAdmixture_4B18 demography, 1e-8 recombination, 1.25e-8 mutation and the four written sample counts. Original sample unit, realization seeds, inference versions/options and original inferred trees remain unavailable. Our generator explicitly chooses 1,600 haplotypes paired into 800 diploid individuals, JC69 mutations, a discrete genome and lineage-destination truth at the generation-12 pulse. Those are concrete study conventions, not evidence of the authors original realization. Native ARGformer training remains per observed ARG, whereas our supervised model uses independent training parents. That supports pipeline comparison with disclosed supervision, not architecture-only attribution.

The common query registry samples 10,000 unique full raw query paths without replacement and assigns each its first-occurrence midpoint. This is label-blind and shared by all methods. It is a reconstruction because the paper does not provide its sampler, occurrence, coordinate or weighting rule. Current retrieval uses the native default k=1 and preserves its scores, indices and tie behavior. The paper does not supply the LAI k or voting rule. Its real-data top-five retrieval is a separate explicitly stated task.

Reference-only PCA with ten components is paper-known. The cluster classifier, scaling, reference weighting, cluster-to-label mapping and ties are not released. The README PCA2 example visualizes aggregated embeddings and does not resolve this gap. Neither do unused generic model classifiers, tests, dependency names or the FLARE2 Gaussian-mixture helper. An inactive, fully specified reference-PCA10 plus nearest-centroid study evaluator is provided, clearly labelled as a proposed reconstruction.

Table 1 contains class precision and recall but no original confusion matrices, replicate uncertainty or overall accuracy. Our external scorer defines class precision/recall/F1, macro F1 and accuracy on the frozen focal records. It reports equal-parent means, sample SD and paired deltas after the prediction barrier. Native hard-call one-hot transport does not become a calibrated posterior. No new score was produced by this review.

The real-data paper and supplement identify the archaic and Oceania-America groups, sample-node/vocabulary/path totals, top-five retrieval, chance-corrected enrichment, ridge probes and attention motifs. Exact source trees, cohort manifests, phasing, balancing, figure code, permutation units/counts, ridge alpha/splits, UMAP settings and attention selection rules remain unavailable. The remediation matrix lists the missing source-backed requirements individually. Generic embedding aggregation does not fill them.

## FLARE native route

FLARE accepts phased, nonmissing multiallelic genotype records, a source-reference panel and a PLINK map in cM. Its reader retains exact shared markers and uses the second-largest reference allele count with the native frequency/MAC threshold. Our converter preserves all observed sites, allele strings and original phased pairs. It does not lower MAC 50 or invent a biallelic-only limitation. The uniform 30 Mb simulation map spans 30 cM.

The generation-10 concern is resolved. With em=true, gen=10 initializes estimation of T and ancestry proportions, rather than fixing the analysis to ten generations. update-p=false preserves the initialized copying probabilities and switch rates during the subsequent EM updates. The generation-12 simulation is therefore not a demonstrated native-parameter mismatch. Our route uses known source panels, no model file and no query ancestry file. The optional FLARE2 panel-probability/clustering route is separate.

Native AN1/AN2 calls use unrounded probabilities. Rounded ANP fields can introduce printed ties, so the adapter correctly preserves the native hard calls and raw posterior strings separately. It maps ancestry headers to the common class order, uses nearest-marker midpoint projection with ties to the right, and carries edge calls to the domain boundaries. Projection is our explicit study choice because Table 1 does not define it. An unused BitArray parser overload contains a duplicated-first-allele assignment, but the active reference-record route uses phasedAlleles/nonMajAlleleIndices; this is not an established active defect.

`agreement_matrix.json` contains 31 individually sourced dispositions: 15 resolved, four conflicts, six explicit study choices and six upstream-unavailable items. `remediation.json` preserves an untouched release control and specifies four separate inactive variants or study evaluators. It does not authorize a launch or modify any active configuration. `file_coverage.json` states the actual per-file review mode, hashes, purpose, decisive ranges, paper disposition and runtime role. `evidence.json` binds primary sources and retained receipts. `COMMIT_SCOPE.md` identifies only this review folder for the primary agent.
