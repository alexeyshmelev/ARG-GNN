# Independent assessment of edge innovation GNN v1

The proposal is a plausible learned inductive bias for retaining reference evidence on inferred carriers before query compression. It is not presently evidence of a new general temporal GNN, correct ancestry persistence, or predictive improvement. The narrow coupling deserves an experiment, but historical priority remains unresolved. Matching Generic or sham would weaken the biological mechanism claim; it would not, by itself, settle historical originality.

**Inspected evidence.** I read the proposal and science packet, GraphSSM fulltext, the GST abstract/introduction, ARGformer methods text, the released ARGMix kernel/GRU and TMRCA-attention source, Ancestral Paths training source, and the simulation demography/sample contract. I also fetched primary TGN, DeltaNet, Gated DeltaNet and Tree-LSTM PDFs read-only and inspected their relevant methods. Source hashes and read anchors are in the receipt. This is a focused mechanism comparison, not an exhaustive priority search. No proposed implementation, target arrays, fits or empirical output artifacts were inspected.

**Concrete equivalents.** TGN already maintains event-updated node memories and feeds those memories into graph attention before producing node embeddings (Rossi et al., arXiv:2006.10637v3, §3.1). Its message/updater interfaces can accept old/new cavity payloads, treat the child as the memory owner, flatten a matrix into a vector, and use the proposed current-tree decoder. This is an equivalence by construction, not an assertion that the published TGN experiments implemented this particular operator. Reading memory before pooling therefore does not distinguish the proposal from TGN generally.

GraphSSM already mixes previous/current graph features or representations, retains history with gap-dependent dynamics, and aligns persistent/new node states (arXiv:2406.00943v2, Eqs. 9, 21). Its published operator is not the proposed associative lookup, and its paper limits its practical treatment of continuous-time event graphs. Nevertheless, previous/current graph conditioning and qualified-identity resets are established ingredients. GST likewise injects collection context back into node propagation, so feedback before final compression alone is not new.

Writing `a=exp(-gap/ell)*gamma`, the proposed pre-tanh update is exactly `a*M*(I-eta*k*k^T)+eta*v*k^T`: Gated DeltaNet's Eq. 10 with differently constructed inputs (arXiv:2412.06464v3). DeltaNet already supplies prediction-error replacement and query-key associative recall (arXiv:2406.06484v6, §2.2). The outer tanh changes dynamics and precludes directly importing their linear parallelization, as the proposal acknowledges. Learned child aggregation and child-specific gates are established in Tree-LSTM (arXiv:1503.00075v3, §3.1); subtree-excluding outside messages are the familiar cavity/rerooting construction. Atomic complete pre/post snapshots give a sensible serialization-independent feature, but not uniquely biological edit attribution.

ARGMix's inspected source already supplies reference-weighted TMRCA votes, TMRCA attention and genomic GRU filtering; Ancestral Paths supplies reference cohort composition and node ages; ARGformer uses shared ancestral-node path tokens and reference retrieval. None of these inspected sources establishes this exact cavity-keyed carrier update plus whole-tree decoder. That absence is weaker than an originality claim.

**Biological logic and confounds.** Census350 is a source-state target, whereas genomic scan direction is spatial ordering, not ancestral time. The inspected demography preserves the four source populations through350 and specifies no migration. Younger pure-reference labels thus have a defensible interpretation at350 in the true simulation. Older references must remain sampling-cohort affinity evidence; the proposal correctly avoids fictitious descendants. Inferred dates/topology still cannot turn either channel into a hard source assignment.

The strongest informative case is a reference-free query subtree with changed outside reference affinity: `Delta_d` can carry evidence even when its own reference state is zero. A second case is a later query attaching to a carrier whose earlier reference environment was informative; query-only recurrence may never have retained that carrier's history. These are useful hypotheses when current pooled contexts alias distinct histories. They require supportive genealogy, not merely many tree edits. Within-source recombination, deep rearrangements above the target date, poor reference coverage and unstable inferred identities can yield changes without a350 source change.

Complete pre/post cavity differences also include simultaneous distant rearrangements and changed descendants. They measure observed contextual change, not the causal contribution of one reattachment. An identity join plus learned retention can exploit an inference algorithm's bookkeeping without preserving a real ancestor. Physical-distance decay is also only a tract prior when recombination rates vary. Four-dimensional keys may collide, and reference-age/class imbalance, fixed roster centering and the frozen emitter's errors can influence where apparent gains occur.

**Necessary matched controls and one improvement.** The proposed Static, instant-edit-equipped Generic and internal-history sham are useful and materially stronger than comparison with a weak emitter. Keep the same reference policy, bidirectionality, resets, physical positions, decoder depth, roster and tuning budget. Match and report actual per-tile state counts, including their tails; median scalar budgets alone do not match computational access. Fit the sham under its own training corruption, report changed lookups/singletons, and check memory norm/key-compatibility distortions. A sham loss demonstrates dependence on coherent observed joins, not true ancestral continuity.

My suggested improvement is one matched **carrier GRU before pooling** arm: exactly the same atomic cavity inputs, qualified carrier episodes, decay/reset policy and whole-tree read, with vector recurrent state replacing conditional matrices. This directly tests the claimed coupling against the nearest TGN-like mechanism. Together with a fresh-state/no-inheritance ablation and a shared-memory post-pooling read comparison, it separates carrier storage, conditional lookup and decoder placement. Preserve parent-level NLL, class/boundary/short-tract measures and disclose repeated development selection. One seed can motivate follow-up; it cannot establish biological generality or priority.
