# H045: contiguous clade-episode context

Question: does sharing learned internal-clade states across consecutive trees improve local ancestry inference beyond an equal-parameter own-state control?

Use exact sampled-descendant leaf sets to identify proper internal clades. A maximal consecutive run of the same proper clade is an episode. A reappearance after any absent tree starts a new episode. Root and singleton clades are excluded. Preserve all original tree vertices and unaries, using the existing deepest representative only for duplicate proper clades along unary chains. This is structural membership, not an assertion that internal ancestral individuals are identical.

For episode members i with physical spans w_i and first-sweep FP32 states h_i, use leave-one-tree-out context m_i = (sum_j w_j h_j - w_i h_i)/(sum_j w_j - w_i). Only episodes with at least two trees receive injection. The own-state control uses m_i = h_i on those identical eligible nodes. Compute the same pool in both arms. The control may retain a zero-gradient link to the pooled value to keep the computation path comparable.

Preserve the complete learned H042 flag adapter, two whole-tree PyG sweeps, SNP features and genomic BiGRU. Add a zero-initialized rank-eight residual O(U(h_i) * V(m_i) + W(h_i)) before the second sweep. Four bias-free 32-by-8 or 8-by-32 projections add 1,024 parameters, for 31,812 per arm. No state is detached across trees. Full-body gradients remain trainable. Use PyG aggregation, no dense tree-pair matrix.

Both arms start from the same H042 pass-30 state, with identical new weights, output O exactly zero, and independent reset AdamW. Use seed 101, FP32, learning rate .001, weight decay .0001, gradient clipping 1, and the same 32 TRAIN/eight VAL parents. Train 30 passes and 960 whole-parent updates per arm. Native-hold exact target mass is appropriate because outputs remain constant per native hold. Six checkpoints per arm produce the original 96-product validation matrix, all sealed before validation truth. Use original common scoring support, cohorts and selection. Outer data remain untouched.

Register practical discovery criteria before execution: at least 0.10 percentage-point mean Present182 accuracy gain over the matched own-state control, without more than one percentage-point boundary F1 loss. This does not establish original-benchmark superiority, significance or architectural novelty. Also compare descriptively against the latest H044 continuation, acknowledging its different readout and input preparation.

Prior-art position: duration-weighted segment pooling, graph coarsening, graph matching and temporal message passing are established ideas. No claim of a new averaging operator, class equivariance or general-purpose graph kernel is made. Priority of this particular contiguous clade-episode construction and utility for ARG inference remain unestablished. A specific literature check is required alongside implementation. It is distinct from H043's nearest changed-clade transfer and H044's within-tree SNP localization.
