# Root integration and exact inference contract

Source-only executable adapter; no simulation, inference, model, actual genotype/tree read, install, download, probe, guard call or resource mutation was performed here. Original generators, native adapters and author sources remain frozen. Six focused stdlib-only fixtures use synthetic full-panel strings/stub tables and a mocked subprocess; they make no native/runtime qualification claim.

The accepted prospective science plan selects Relate1.2.4 All, mu1.25e-8, N30000 and no extra postprocessing. The exact author binaries are reused. The older AP relate.sh also calls five population-size iterations; that is a different recipe and no relate_size_base seeds are registered in the accepted77-seed registry. This adapter follows the accepted All recipe and does not silently add that size step. It does not claim to reproduce the whole original AP shell pipeline or published results.

Inference has exactly four native commands:
1. RelateFileFormats ConvertFromVcf, reading the shared observed VCF directly by its public prefix; writes new converted haps/sample under a fresh admitted input directory.
2. Canonicalize only converted.sample IDs into input.sample (same ID_1/ID_2 per diploid), retain converter original, and stream-verify every native haps field/allele/phase/position/variant ID against original haps+VCF+variant manifest. Then GenerateSNPAnnotations with real observed cohort labels.
3. Relate --mode All -m1.25e-8 -N30000 --memory2 --seed REGISTERED_relate_initial --haps ... --sample ... --sample_ages ... --map ... --annot ... -o inferred.
4. RelateFileFormats --mode ConvertToTreeSequence -i inferred -o converted.

The unchanged binary All path is serial; one root-selected CPU is used. No added --fb, --coal, postprocess, optimization, masks, site filters, sample dropping, new seeds, size iterations or retries occur. Source-pinned software/installation metadata and actual argv/native OS waits are retained. Successful outer script status alone is insufficient.
