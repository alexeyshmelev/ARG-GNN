## Scientific objective and gradient

For block b, let E_b(theta) be the original encoder over every tree node and every H=1600 haplotype. Let P select the same Q=1000 unknown query columns in every tree. Both directional GRUs act independently on their batch columns. References have no focal losses and no operation mixes recurrent batch columns. Therefore scanning P E_b gives the same query states as selecting P from the full-H scan, subject to ordinary FP32 kernel differences.

Every original focal label is used once. The loss remains the unweighted mean cross entropy over all 10000 original query records in a complete independent 2 Mb parent. Both recurrent directions carry state over every block without detach or reset. One global gradient norm clip and one original AdamW update follow the complete-parent gradient.

The two-phase chain rule is dL/dtheta = sum_b J(E_b)^T P^T dL/d(P E_b), plus the direct GRU/head parameter gradients. The first phase computes unchanged full-graph context values without retaining the encoder graph. The recurrent/head backward produces a complete adjoint for every selected context. The second phase reruns the unchanged full-graph encoder and applies that adjoint. Learned contexts never survive an optimizer update. Source, tensor version, model parameter version, RNG and FP32 checks reject unsupported mutation or stochastic layers.
