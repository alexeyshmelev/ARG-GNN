## Remediation of independent review findings

C3-MLM-01/P1: corpus_auth_v2.py authenticates exactly the completed v3 MLM train, MLM validation and standalone vocab refs once, in8MiB streaming chunks, at the full stage's quiescent pre-load boundary. It checks canonical regular files, O_NOFOLLOW open, single links, source serialization size bound and equal descriptor/path dev,inode,mode,size,mtime,ctime,nlink before and after reading. A final stat/shadow-tokenized check immediately precedes unchanged author main. Successful evidence is an own child JSON referenced by both child and full completion. It does not decode/copy the corpus, hash per update, consume row-order sidecars or authenticate other retained views. The synthetic qualifier never invokes this hook. The existing READONLY/revoked-writer assumption continues after verification; this is not an OS content-lock sandbox.

C3-MLM-02/P2: owned_lifecycle_v2.py tracks actual direct/adopted descendants and their PID/start identities. All inner termination uses pidfd_send_signal after identity checks before and after pidfd acquisition. An acquired pidfd cannot retarget a later reused PID. There are no positive numeric process-group signals in the inner supervisor, including signal handlers, post-poll/post-wait drain and exception cleanup. Numeric killpg(...,0) is observation only. Actual direct wait, adopted wait records and original-identity absence precede scope/hash/log access. If a numeric PGID remains after all original owned identities drain, it is never signaled or reported ESRCH; the stage fails closed. Its failed artifacts and real wait remain preserved. Root's original strict group-absence/close gates and outer ownership functions remain unchanged.

Linux pidfd APIs are required before the native child is spawned; there is no raw-PID/group-signal fallback. The first shared-supervisor/native qualifier launch still needs actual integration qualification. No real process, GPU, corpus or guard was touched by the source checks.

Focused added checks use equal-length tampered synthetic bytes, changed file identities/size caps and mocked PID reuse before/during/after pidfd acquisition, group disappearance and group reuse. They execute source-extracted pure helpers with fake streams/stats/syscalls. The existing dictionary-result/integer0 CLI regression check is retained.
