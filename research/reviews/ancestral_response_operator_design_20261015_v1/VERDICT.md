# Verdict

**No-go as the next architecture direction.** Gaussian ancestral-state elimination is a valid sample-level response, but exactly Kron reduction/Gaussian tree inference. H033 already implements the anchored solve and differentiable backward. The exact rank-one edge response is in Dörfler–Bullo §3.4/Theorem 17/eq.(35).

Small-rank updates need a fixed coordinate/grounding model and genuinely local coefficient changes. They are not an exact low-rank heat-kernel update. Public Relate conversion creates new internal IDs per tree; tsinfer includes synthetic compression ancestors. Stable samples are sufficient to define the operator, but do not certify cheap internal edit updates.

Ordered response factors can fail to commute. This is classical time-varying dynamics; exact edit updates of the response itself are path-independent. No new general operator, exact shared-ARG complexity gain, or measured biological failure specific to this mechanism is established.
