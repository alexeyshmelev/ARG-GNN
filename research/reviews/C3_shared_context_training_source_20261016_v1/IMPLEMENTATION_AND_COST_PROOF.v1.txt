Algorithm and chain-rule argument
For each unchanged complete parent, phase1 calls original encode_bank once per block under no_grad and retains FP32 CPU context leaves c_b. It copies only authenticated focal indexes and global-neighbor geometry from that same provider.get, so there is no separate get solely for row IDs.
Phase2 runs original forward/reverse GRUs in original block orders with full hidden carries and no recurrent detach/reset. It uses original classifier, summed CE per chunk, and one mean over every10000 original focal. One total loss.backward accumulates head/GRU parameter gradients and the combined forward, reverse and direct-head adjoint g_b onto each CPU context leaf.
Phase3 re-reads/authenticates each original observation block once, re-encodes it at unchanged weights, and backpropagates J_encoder(b)^T g_b. Then the original finite checks, one global clip at1, and one AdamW step occur. Parameter version and RNG state checks reject mutation/stochastic behavior between phases. Contexts and adjoints are discarded within the step; none cross an optimizer update.

For L=G(c_1(theta_e),...,c_B(theta_e),theta_GRU,theta_head), the encoder gradient is sum_b J_b^T*(dL/dc_b). Phase2 supplies the whole derivative, including both recurrent directions and direct local readout. Thus the deliberate context leaf cut is completed by exact VJPs; it does not truncate recurrent BPTT. All updates use the same pre-update parameters. FP32 summation order and max-pooling tie subgradients can differ; bitwise gradient equivalence is not claimed.

Source-defined production cost
Let B be complete physical blocks and Q=sum_b ceil(sites_b/256).
- Encoder entries: B value forwards + B gradient re-encodes =2B, replacing original4B.
- Encoder backward graphs: B, replacing original2B.
- Site-chunk/MLP entries with original checkpoint_sites=True: Q no-grad forwards + Q grad forwards + Q inner checkpoint replays =3Q, replacing original6Q.
- Directional GRUs remain2B initial +2B replay entries and2B backward graphs.
- Classifier remains2*ceil(10000/focal_chunk_size) forward/replay entries.
- One full-parent loss.backward plus B encoder VJP backward calls; one optimizer step after all phases.
- provider.get:2B, each passing the existing provider's full authentication, replacing original6B.
These count callable entries/graphs, not kernel FLOPs or wall time. Non-reentrant checkpoint early stop may omit a replay suffix. Fixture-only no-grad logits diagnostics add head calls and are excluded from production counts. No speedup or full-run fit has been measured.
