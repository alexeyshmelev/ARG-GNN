# Primary current-author backend, source-only handoff

Pinned author commit: c2481248eb0de5fda659d68f59c51e0e27becd20.

This packet proposes the primary current-author comparator on the frozen prospective1611 observed panels. All86 copied author files remain unchanged. It is not the unavailable April paper architecture or an exact reconstruction of its results. The new outer project CLI currently assumes forward-simulated ADMIX, so the packet supplies external structured YAML directly to its unchanged build_training and train_joint_model.py backends.

The older100k-only shared-row/legacy-sampler adapter remains unchanged and is a development sensitivity. The frozen100k target list remains unchanged. It is not silently reused as the primary native training context.

## Exact entry points

Import primary_native_v1.py only in a root-admitted job using the existing project environment and real root callbacks. The module performs no imports of NumPy, tskit, msprime, Torch, native code or work at import. No generated panel, native source binary, model or numerical array was executed/read in authoring this packet.

1. materialize_author_copy(output, guard=guard) writes the authenticated unchanged86-file source copy and returns a build-only plan. Root must create the fresh owned output parent first. Build argv is cargo locked release/no-default-features/bin build_training, with all build caches/TMP under the owned copy. Root owns admission and actual native qualification.
2. For each fiveTRAIN, oneVAL and threeIID parent, prepare_observed_parent(generator_config, parent_id, parent_output, inferred_output, support_output, output, guard=guard, resource_check=resource_check) writes only observed metadata, exact raw native-coordinate references, the header-standardized map, the native support mask and exact archive row counts. Set CUDA_VISIBLE_DEVICES empty. The original native .trees, .haps and .sample are linked by authenticated refs, never regenerated.
3. For each of the six TRAIN/VAL parents only, build_truth_npz(plan_record, parent_output, output, guard=guard, resource_check=resource_check) streams full external census labels for every original observed SNP and all3222 haplotypes into a single ZIP_STORED NPZ. It rejects IID. No second full raw matrix is created. Native keys are variant_pos int64, truth__hap_labels int16, truth__sample_ids Unicode and ancestry_names Unicode. Haplotype columns remain exact sample_id/h0/h1 order. Labels are right-continuous census350 ancestry at original p0, format position is p0+1.
4. prepare_native_backend(train_plan_records, val_plan_records, truth_records, copy_record, output, guard=guard) requires exact5+1 parents and validated full SNP truth. It merges the intact author default dictionary with the intact author template and writes native backend YAML, pairs YAML and argv. It launches nothing. Root independently admits the full archives before running either builder and the full model before fitting.
5. Root runs unchanged author trainer via native_train_launcher_v1.py to supply the required process title and physicalGPU0 restriction. The launcher changes no author definitions, tensors, objective, seed, optimizer or model.

Record args are bounded JSON file refs with path/SHA256, not in-memory result dicts. Use ref(output/'observed_plan.json'), ref(output/'truth_format.json') and ref(copy_output/'untouched_copy.json').

A real runtime HashMap supplies the reference vector as in untouched author code. It is not overridden by roster order.

Every native eligible labelled row is retained. The native first/last raw-tree exclusion remains true, no-SNP intervals are dropped by native TruthResolver, first_snp/no-purity supervision remains unchanged, all native queries remain, caps remain None, TRAIN nearest-drop1 and VAL0 remain. Native per-query1024/512 canonical chunking, row masks, cM spans, optimizer, native batch-mean validation loss and checkpoint selection remain unchanged.

Important correction: DEFAULT_ADVANCED fallback says3epochs, but the shipped forward_blank template says20epochs and overrides that fallback. ## Coordinate and identity contract

The primary backend consumes raw Relate-converted native_tree_ref in position=p0+1 coordinates together with original input.haps and input.sample. This avoids mixing parents with different cleaned local coordinate offsets into one recombination map. The numeric native map is unchanged. Only its header is standardized to recognized position/rate/cM column names, because the generator's Relate-native header does not match the current ARGMix map parser.

Native TruthResolver assumes sample nodes are0..3221 in two contiguous haplotypes per diploid sample order. The bridge checks that exact requirement against authenticated raw native samples, explicit joined sample roster and original .sample names. It stops rather than silently reindexing.

## Scientific differences that must be reported

Same observed panels, donor/query identity policy and observed native Relate topology are shared. The primary native fit uses more than500k shared midpoint labels. It uses full native eligible observed-SNP labels and native recurrent context. Shared midpoint evaluation can disagree with its first-SNP training targets when ancestry changes within an inferred interval. This is the author loss/data rule, not an altered implementation. The primary comparison therefore describes each method's training-label count and native preparation rather than asserting identical supervision budgets.

For an equal-information main study, our method should also be allowed the same full TRAIN/VAL census supervision ceiling, with each native method's training policy reported. The original100k matched-budget route is a separately labelled sensitivity. All panels remain prospective synthetic reconstructions with disclosed choices, not the original author's data/seeds/April recipe.

## Capacity before archive extraction

The observed plan counts default-native SNP-eligible trees using exact floor(left),ceil(right) membership, independent of ancestry truth. Full truth bridge then checks every observed-SNP/haplotype class is valid. Under that verified condition each query has exactly the same eligible interval countN.

Chunks per query are0 whenN=0, else1+max(0,ceil((N-1024)/512)). Native padded rows are2972 times chunks times1024. Native archive array payload is657bytes per padded row: IDs128, matrix512, label8, mask1, cM8. NPZ output is Stored and duplicates overlapping chunk rows. The builder simultaneously keeps native Row vectors and dense chunk arrays, and native training fully loads bothTRAIN andVAL archives.

The source plan supplies counted full archive payload/ceilings and a clearly labelled x64 native Row payload/structure estimate728bytes per original supervised row. It does not claim current server capacity suffices. Root's existing resource guard and supervisor decide admission, accounting for all current project bytes and actual RSS overhead. No caps, thinning or alternate storage/accounting framework are introduced to fit. If native exact archives cannot fit the1TB project limit, preserve the failed admission and choose a separately reviewed storage-only representation that retains identical native row eligibility, tensor chunks and supervision, never silently run the100k adapter as native.
