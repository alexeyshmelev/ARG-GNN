# Bounded assessment: interval functions on a persistent ARG DAG

**Worth pursuing as a precise computational question, with an early mathematical stop condition.** A support-aware functional DAG could avoid repeated storage of identical ancestry structure and admit site-dependent readouts. The proposed global low-rank interval-integral version, however, does not by itself meet the locality requirement. Exact invariance to edge-row splitting and avoidance of disjoint-locus evidence mixing are different properties. The former is straightforward with additive interval measures. The latter conflicts with generic finite global Fourier/Galerkin compression. The work to justify is a support-preserving representation with an explicit cost/error tradeoff, rather than “one shared DAG pass” or coordinate features alone. No priority, predictive benefit, or empirical efficiency is established here.

Scope: literature/design only. The supplied counts—106,769 observed nodes, 603,762 interval-edge rows, 76,863 marginal trees, 1,600 samples—are problem assumptions supplied by root, not independently inspected data. No project source, model, data, metric, runtime, guard, process, or GPU state was read or changed during this follow-up. Only public literature was retrieved, with notes and citations confined to this subfolder. No implementation or experiment was performed.

## The strongest obstacle

An ARG edge is a relationship plus a support set: `(parent, child, I)`. In the union DAG, an ancestry path can have consecutive edges whose supports do not overlap. A conventional GNN on this union graph sends messages along that impossible path. Gating only the final readout cannot undo the mixing. Every step must preserve the intersection of the intervals along the path.

Suppose a coordinate basis has K functions φ and an interval is encoded by the matrix `M_I[j,k] = integral_I φ_j(x) φ_k(x) dx`. It satisfies `M_[l,r) = M_[l,s) + M_[s,r)`. That gives interval-splitting invariance if all other edge features and normalizations are unchanged. It does **not** give locality. At K=1 with a constant basis on [0,1), a child contribution present only on [0,1/2) becomes its half-span average at the parent, including at x in [1/2,1). More generally, a nonzero finite trigonometric polynomial cannot vanish on an open inactive interval. Projecting an interval-masked field onto a finite global Fourier basis therefore creates leakage.

An exact external support mask prevents leakage outside that particular mask, but does not automatically prevent evidence from one part of a parent's support altering reconstructed values elsewhere inside that support. Projection/nonlinearity also do not commute: in general `P sigma(f) != sigma(P f)` and `integral sigma(f) != sigma(integral f)`. A globally pooled coefficient state is not a locus-specific state just because it is evaluated at a coordinate afterward.

A strict useful definition is: for fixed parameters, output at x depends only on the active graph at x and the declared observation context at x. If a finite local genomic window is allowed, define it explicitly. Shared ancestral identity alone must create no additional cross-coordinate dependence. The exact operator below has this property. Generic finite-rank projection weakens it to an approximation/leakage bound unless it represents the relevant functions exactly.

## One minimal falsifiable formulation

Define an **exact coordinate-local reference operator** before choosing compression. Each node stores the meaning of a function `h_v(x)` rather than a single integrated vector. For one child-to-parent sweep, use

`h_v(x) = sigma(B b_v(x) + sum_(c->v) 1_Icv(x) A_theta(age_v-age_c) h_c(x))`.

Here b_v(x) contains only observed node/sample attributes and a declared site-local observation encoder. A low-rank factorization of A is allowed, but feature-channel rank must be distinguished from genomic-coordinate rank. A second parent-to-child sweep may use the same interval restriction and recipient exclusion. The site readout evaluates at x and conditions on observed SNP/mutation features at x. This permits different outputs inside one inferred-tree interval without claiming that those changes are true ancestry boundaries.

All equivalent rows are treated as the same relationship with unioned support and identical biological features. Global coordinate x may be used, but a learned feature based on a stored row's left/right endpoints, raw row count, or raw union-graph degree can break subdivision invariance. Normalization must be computed from the active relationships at x. Half-open intervals settle endpoint ownership.

The resulting reference operator has three directly provable properties: interval-row splitting leaves it unchanged in exact arithmetic, consistent node relabeling is equivariant, and each message path has support contained in the intersection of its edge supports. These are semantic correctness properties, not by themselves a sufficient research contribution.

The bounded research question is whether an executor can retain those semantics with **certified**, materially smaller function complexity. Let C be the total stored interval-function pieces/coefficients and J the total edge–piece interactions. State costs in C, J, feature rank, depth and number of requested sample-site outputs Q. Do not substitute N+E for these quantities. Dense K-by-K interval moment matrices can cost O(E K^2 r), and output materialization alone costs at least O(Q). A single global topological traversal does not imply a single constant-size update per node.

For a compressed approximation, an honest candidate theorem is a nodewise bound

`delta_v <= epsilon_v + sum_c L_sigma ||A_cv|| delta_c`,

where epsilon_v is a certified local approximation residual. DAG path products propagate the errors. A uniform bound such as epsilon/(1-rho) needs an explicit contraction condition with weighted incoming norms at most rho<1. Without such conditions, deep ancestry and high fan-in can amplify error. A norm averaged over genomic length can conceal complete failure on short intervals, so a querywise or suitably localized bound is needed for short-tract readout.

**Falsifiable stop condition:** if the stipulated locality cannot be preserved, or the certified representation needs essentially the marginal-tree/SNP expansion at the required resolution, the proposed efficiency premise fails. A fixed global coordinate rank with arbitrary locus-specific inputs cannot be assumed to succeed. Exact piecewise functions may require all descendant breakpoints, even when one ancestor node is shared. Conversely, a result relating C and error to a nontrivial, explicitly stated ARG/feature class would answer a substantive question. A generic universal-approximation theorem or only the additive split identity would not answer it.

## Biological validity and generalization

Persistent nodes represent genomes, not a locus-independent ancestry label. Using one vector may conflate different descendant sets or ancestry mosaics. Inferred node identity, times and mutation placements are uncertain and method dependent. The operator must not turn cross-locus identity into certainty about genealogical homology. Mutations need site-specific treatment of missing data, recurrent/back mutations, multiple alleles and uncertain placement. No-SNP evidence is not interchangeable with an observed reference allele. The site decoder must not be described as adding biological resolution merely because it can draw more boundaries.

Edge-row splitting is only one representation equivalence. Adding/removing unary ancestors or simplifying a tree sequence can preserve selected sample relationships while changing graph depth and node metadata. The proposed guarantee does not automatically cover those changes. Also retain sampled ancestors, multifurcations, disjoint support and multiple roots when the observation permits them. An operation valid only for complete binary marginal trees would miss much of the general ARG representation.

The mathematical definition extends naturally to graphs indexed by a one-dimensional parameter with persistent entity interfaces and interval-valid relationships, for example versioned provenance DAGs. The same pointwise semantics and row-subdivision quotient apply. Cyclic infrastructure graphs require a fixed number of message-passing layers or a convergence assumption, rather than one topological sweep. If the parameter is real time and historical influence is intended, that must be added explicitly as a causal kernel. Such generalization connects directly to neural operators and sheaf restriction maps. Its value would depend on the same cost/error/locality result, rather than a relabeling of genomic coordinate as time.
