# Independent shared-pool source review

Verdict: PASS for the exact source/config and supplied inactive placeholder plan. There are no concrete source blockers in this review. The inactive plan is not operationally qualified: root must complete reservations, hashes, commands, memory bounds and time window, then obtain a new independent PASS bound to that completed plan digest. Changing the plan invalidates this receipt in the source validator.

The companion leaves original acquire_device and Controller supervision, PID/UUID attribution, two-device cap, inherited lease FD, pending-CUDA memory, FIFO, subprocess argv/environment, draining and shutdown implementations intact. Its two behavioral overrides add exact registered-spec and root/source/storage validation. Its storage object uses the unchanged budgetv4 checker code with a private mutex global; it never reserves or changes either ledger.

Fresh independent fixtures use three contained fake pool plans with four jobs each, four inert Popen objects, handmade inventory/proc metadata, fake ledgers and private budget constants only. They run the actual original start/acquire_device, submit, memory, queue, tick and natural drain/shutdown methods. No scientific module or array is imported. Subreaper changes and actual worker Popen are replaced in the test process and restored.

Descriptor counterexamples reject absent/unlocked and shared-flock ownership and multiply linked scheduler files. The original start has one scheduler EX-flock and four device lock attempts; the storage callback adds no lock/unlock. The private checker retains its code object and leaves original globals untouched. Closing the borrowed duplicate, including after an exception, leaves the original open-description exclusive lock held.

The tests independently reject a third fake physical device; changed root plan, pending review, expired root authority, wrong command hash, source/config/runtime/worker-review drift, absent unlaunched own reservation, stale initial ledger pins, current global950GB overflow and filesystem free-space exhaustion. They accept and account for a valid unrelated reservation change. Memory tests include no-CUDA-initialization reservations, strict FIFO blocking of a later smaller fitting job, actual UUID drift, foreign compute PID, attributed peak overrun and unknown lease holder. Leader exit retains its reservation until a recorded descendant drains. Natural drain reuses the same original device FD/inode/hash, and shutdown removes only owned sockets.

Both fake ledger byte strings and original source/config/author artifact hashes remain unchanged. Fixture roots are removed only after owned handles close. There are no live device queries, GPU/model jobs, production locks, live ledger reads/writes, source edits, installations or Git operations. The measured source check report records the count and timing. Controller/job scope accounting remains contractual rather than an OS quota; the existing documented controller socket/log/registry behavior remains part of the inherited contract.
