# Generation and external truth contracts

This packet implements a prospective synthetic1611 condition; it is not an original-paper reproduction. Original AP and reviewed adapter sources remain frozen. Numerical paths are deferred.

## Frozen science

The pinned fair-comparison config supplies all1611diploids/3222haps, dates, retained demography and existing77-seed/14-parent registry. This implementation accepts the five TRAIN, one VAL and three IID parent IDs. It refuses every OOD parent until separately realized demographic dictionaries are frozen. No default OOD draws, chromosome length, map, interval or uniform recombination fallback exists.

Ancestry is standard coalescent, discrete genome, explicit diploid SampleSets. The original AP population insertion order is preserved with the unused, unsampled, noncontributing terminal BAA population/event omitted. Retained sizes/events/dates are unchanged from the prospective config; census350 remains. The omission supports equality of retained marginal stochastic law, not identical seeded realizations or proof of the April implementation.

Mutations use explicit msprime.BinaryMutationModel(state_independent=False), rate1.25e-8, discrete genome, the registered mutation seed. Error uses numpy.Generator(PCG64(registered genotype_error seed)). At every simulated mutation site in increasing position, draw one uniform for every haplotype in frozen roster order; draw<.001 flips0/1 independently in all eight cohorts. Draw==.001 does not flip. Drop invariant observed rows after error, retain binary segregating rows and known phase. Draws are made before filtering, including sites subsequently removed. This is the explicitly new prospective error rule, not the paper's unspecified mechanism. Qualified exact package versions/files and interpreter digest are mandatory, because seeded implementations are version-dependent.

## Generation request and runtime/resource bindings

The inactive request template deliberately refuses execution. Root must freeze every path/hash, set root_approved=true after the independent resource/admission workflow, and bind the exact generator/science source. Outputs are three fresh, separate, nonnested directories: public observed, private truth, private receipts. No overwrite, retry seed, site-count target, support resampling or map fallback is implemented.

The runtime binding requires root_qualified/cpu_only, interpreter SHA, exact msprime/numpy/tskit versions and imported file hashes plus a qualification-receipt digest. The loaded process checks those identities only inside numerical commands. The external truth stage uses the same qualified interpreter/tskit binding. Resource binding requires root-approved wrapper/admission digests, CPUthreads1 and positive RSS/time/observed/truth/receipt caps. This source does not monitor RSS or enforce wall time; root's wrapper must do so. Native truth-dump size is checked after write and requires an external disk quota while writing. Streaming observed text has a byte cap and total observed bytes are checked. The cap proposal is an unmeasured fail-stop allowance, not a measured fit/resource proof.

## Output identities and observations

SampleSets are created per synthetic diploid. Allocation inspects actual simulated sample nodes and individual IDs, requires exactly two sample nodes with one population/date per individual, and matches roster population/date groups. Synthetic names are allocated in stable roster order; phase is actual ts.samples encounter order within the paired individual and is recorded explicitly. No consecutive-node, population-offset or individual-offset arithmetic is used. Truth node IDs and sample IDs are not renumbered; metadata attachment never simplifies genealogy. Mutation retains those nodes and census350. Private sample_allocation.json records actual individual/node joins; simulation_node_mapping.json uses the exact reviewed simulation_haplotype_node_mapping_v1 schema.

Public files: observed.vcf, observed.haps, observed.sample, variants.tsv, haplotypes.tsv, roster.unbound.json, map_binding.json, observed_generation_receipt.json. VCF and Oxford haps are two encodings of ONE realized observed genotype bank, in identical phased haplotype order; REF=A encodes0 and ALT=C encodes1. Haplotype TSV records column/diploid/phase/cohort/integer date, not simulation genealogy or ancestry labels. All3222 haplotypes remain.

Internal physical coordinates are0-based[0,L). VCF and standard Oxford haps POS encode internal_x+1. variants.tsv records internal0-based, encoded1-based and source_start+internal coordinates. The later Relate stage must freeze its map/input encoding and explicitly convert the inferred bank into the common0-based[0,L) coordinate system; it must not silently treat encoded1-based positions as truth/map coordinates. This generator does not implement or assert that future conversion.

Public receipt contains observed-file hashes, the exact map receipt identity, coordinates, observed sample/site counts and source/error protocol. It contains no true genealogy or founder-state paths. Original truth genotypes, all-site error count/bitstream digest and full source/private-truth provenance remain in the private generation receipt.

## Private truth and later inferred-bank contract

Private files: simulation.trees (full mutated genealogy with exact census350; never simplified), simulation_node_mapping.json, sample_allocation.json, population_mapping.json and demography.json. The generation receipt binds the exact request, registered seeds, runtime/resource/map/science/source identities, all observed/private file bytes/hashes and explicit coordinate/ID allocation semantics. NF samples have simulation populationNeo; Post/Present have present_bronze; sampled cohort role never substitutes for four-founder truth.

No target labels can be made until the actual shared inferred-tree midpoint manifest exists. The separate external-truth entrypoint then verifies all private and public generation bytes, a future inferred-bank receipt, actual observed-ID mapping→bound roster, common target metadata, and the distinct observed-tree hash. It rejects a direct true-tree copy. The future inferred receipt must have schema prospective1611_inferred_bank_receipt_v1, complete=true, parent_id, exact observed_generation_receipt_sha256, map_derivation_receipt_sha256, sequence_length_bp=L, true_genealogy_used_as_input=false, coordinate_transform={export_position_encoding:"POS=rebased_bp+1",normalized_tree_coordinates:"rebased_bp_zero_based_half_open",map_relate_transform_receipt_sha256:<actual frozen transform receipt SHA>}, and exactly three files entries observed_trees/roster/observed_node_mapping with path/bytes/SHA. The future Relate source must separately authenticate actual commands/software/input provenance; receipt claims alone are not proof of the inference implementation.

external-truth invokes the unchanged reviewed truth_adapter.construct_common_labels. It reads the exact simulation ancestor at census350 at each shared inferred-tree midpoint, requires one of Ana/CHG/WHG/EHG and right-continuous lookup, with explicit simulation mapping separate from observed IDs. Output labels.jsonl and labels.jsonl.contract.json remain outside the public observed directory. The contract is accepted by the reviewed adapter validator and adds generation/inference receipt hashes. Both methods must consume the same label/contract bytes. No model, feature extractor, target sampler or inference command receives the true genealogy from this generator.
