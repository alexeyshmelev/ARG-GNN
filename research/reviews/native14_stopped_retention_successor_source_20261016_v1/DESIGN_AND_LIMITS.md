# Narrow source design and preservation limits

native14_stopped_retention_v1.py is an isolated successor over the unchanged active Census child source/policy. It uses a new journal namespace and freezes only a future actual parent prefix selected by ROOT. The ordinary reserve/close/check/storage/writer and consumer64 functions remain AST-identical. The new event branch accepts one hardcoded key/reservation/charge and all three original roots.

The observed historical stop is a failure. The exact old storage expiry is retained even while unexpired. Permanent cooperative revocation and explicit ROOT acceptance of residual historical uncertainty form a new proposed retention-only authority. Neither source review, tiny fixtures nor the sealed audit grant that authority. Original v8 exit/optimizer and historical full drain remain unknown. The original latest alias receipt is metadata02; no successful namespace03 receipt is assumed.

The measurement deliberately differs from the original regular-file-only census only inside this new exact-key stopped branch. Original live writer checks retain their original implementation. The old branch could not count a retained symlink or socket. Following a latest alias would both leave its own stored metadata uncounted and risk reaching an external target. Excluding sockets would omit genuine retained namespace nodes. The new helper instead lstat-counts links and kernel-inactive sockets in place. Its per-node charge is max(st_size,st_blocks*512)+4096, with every directory included. This is a conservative contractual extension of existing accounting, with positive metadata allowance; it is not a physical NFS usage measurement or quota guarantee.

Paths are lexically contained, all ancestors are opened relative to a stable project directory descriptor with O_DIRECTORY|O_NOFOLLOW, and every descended directory is checked before/after listing. Each stat includes device, inode, mode, uid/gid, links, logical size, blocks and nanosecond mtime/ctime. The helper compares two full inventories, then revalidates every named node through no-follow ancestors. Stored link text is only read as link metadata and hashed; its target is never resolved or opened. Same-device and finite depth/node bounds apply. Reused node identities, non-directory hardlinks, unsupported special nodes, ambiguous control names and all observed races reject. Only no-follow directory descriptors are opened by the census.

Every socket discovered by the full census has a fresh exact kernel-endpoint absence check during both inventories and final verification. The separate ROOT target certificate additionally covers the24 source-recorded old filesystem endpoints and known v12 abstract prefix. Existing stale nodes must retain their original recorded metadata; changed or live nodes block. No socket connection, unlink or namespace remedy is implemented. Fresh PID/group checks are numeric ESRCH, which conservatively block numeric reuse. Six old PID starts remain explicit UNKNOWN and are never synthesized.

Three exact entire roots are required, including all old and amended children, TMP and AUX. The helper will block if a root is missing or linked. The native certificate consumer checks all root summaries and the original14GiB cap. It cannot choose a successful subset, normalize latest, ignore a socket or substitute a child directory. Original markers/source bindings pass through unchanged ancestor scope validation. An unexpected original/v12 completion pathname blocks stopped-only disposition.

The manifest authenticates222 source and compact metadata references, including all explicit historical45 and current23 guard refs. All89 audit reference records remain preserved. Original binary wait frames, activation tokens and historical AGENTS identity are declared historical references bound through the sealed audit/extracts; they are not silently claimed to have been freshly re-read or probed. The sealed direct-wait extract checks were performed by the prior evidence task and are authenticated here. This source task reads no original payload or stdout tail.

This is the union of retained original/v11/v12 metadata and committed native/launcher/outer identity frames. It is not a complete inventory of lost v8 descendants or external NFS writers. Source and actual ROOT certificates preserve that limitation.
