# Hypothesis-only option: observed-input-conditioned hold rates

Status: evidence-independent research option, not implemented, selected, or claimed novel. No result from an existing pilot or development validation set motivates or supports the option described here. A future study would require a separate reviewed implementation, admission tests, search budget and frozen claim scope before fitting.

The current cached boundary construction permits a restricted extension: multiply an entire observed hold's fixed plain/age boundary response by a positive scalar shared across its query/reference nodes. For hold `g`, an observed-only, graph-local and permutation-invariant conditioner could produce `rho_g = exp(f_phi(u_g))`. Initializing the last conditioner layer to zero gives `rho_g=1` exactly, recovering the reviewed global-rate model. A channel/branch-specific variant may use `rho_g,s,h` provided each value is still a scalar across all query nodes and multiplies both corresponding `Cqq` and `Cqr` blocks. A single scalar per hold is the smallest hypothesis and the easiest capacity control.

For nonnegative learned global coupling `lambda`, strictly positive damping `delta`, and a certified cached response `Cqq=U diag(c) U.T`, the hold generator would be

```
A_g = -lambda * rho_g * Cqq_g - delta * I
F_g = bounded_query_source_g - lambda * rho_g * Cqr_g * bounded_reference_source_g.
```

The scalar leaves each cached eigenvector basis `U_g` unchanged; only spectral eigenvalues/rates are scaled. Multiplying a symmetric positive semidefinite `Cqq` by a positive scalar preserves its positive semidefiniteness. Certified nonpositive off-diagonal entries make `A_g` Metzler. Nonnegative reference-grounding row sums give `A_g 1 <= -delta 1`, so each nonnegative-duration homogeneous transition remains nonnegative and has row mass at most one. These are local operator properties; they do not by themselves prove a Mercer-PSD property for an arbitrary normalized neural readout or a globally assembled kernel. Any claimed global symmetry/PSD contract must be rederived for the exact extension and checked independently before implementation is admitted.

The signal and matching ones/mass systems must use the identical conditioned scalar, reference block, hold durations, and numerical flow rule. Scaling only `Cqq`, only the signal forcing, or only the learned source term would change the reference-grounding/mass identity. Damping must remain positive and finite; numerical overflow, negative mass beyond certified roundoff, and near-zero normalization require explicit rejection rather than hidden clipping. Bounded log-rate ranges or an identity-centered positive bounded map are possible future engineering choices, but would need their own frozen specification and sensitivity study.

Both source/readout and redundant-hold contracts constrain the conditioner. It must depend only on independently prepared observed source inputs, before any target decoding. Target coordinates, target count/order, numeric IDs, external query labels/truth annotations, recurrent target states and validation outcomes cannot be inputs. For redundant subdivision invariance, two adjacent subdivisions of the same observed hold must receive the exact same scalar and source. A conditioner on graph-local invariant leaf features and certified boundary geometry could satisfy this; one using interval endpoints, interval width, record index/count, or separately sampled dropout would generally fail. If coordinate dependence is desired, the model would instead need a consistently defined continuous physical rate field and an appropriate exact integration contract; it cannot silently reuse a constant-hold proof.

The existing precomputed homogeneous-bag eigensystem assumes global hold-independent rates. Input-conditioned, trainable hold scalars generally change the weighted bag operator and invalidate that fixed eigencache. A future proposal should either keep bag controls at `rho=1`, restrict to a separately proven commuting construction, or review another exact method. Reusing the old bag eigenpairs after learning `rho_g` would be inadmissible. The ordered per-hold construction retains each fixed eigenbasis and is the direct extension considered here.

Possible future controls are an identity-frozen conditioner, parameter-matched observed-source MLP without rate conditioning, scalar geometry-only versus feature-conditioned rates, shared scalar versus branch/channel scalars, and diagonal/gain-matched controls using the exact same conditioned source/rate realization. These are hypotheses about expressivity and information access. They are not proposed additions to an active or already scored grid, evidence of mechanism, or a novelty assertion. Future admission would need exact identity recovery, forward/gradient finiteness, positive operator/row-mass checks, matched ones-system checks, cached-basis agreement, label/ID/readout counterfactuals, and redundant-subdivision tests before a fresh selection plan is frozen.
