# GST-LAI-8 adapted architecture baseline

GST-LAI-8 uses the unchanged public GraphSetConv from commit `6469d56aa131463325058b897b1e435c6d2edcd2`, source SHA256 `bc08c15d55247b32bda98e4b03fcaee988ceb8f654423240a33ca632ce11ef72`. It adds a fresh LAI input frontend and a native six-class node head. This is a new shared-task pipeline comparison. It does not reproduce GST's synthetic or molecular tables, resolve the paper's two-gate architecture discrepancy, or isolate the contribution of one layer.

The first condition uses the exact existing AP476 observations and frozen focal registries. Every native tree, real edge, retained SNP and sample is visited. A set contains eight consecutive complete native trees; the final set may be shorter. GraphSetConv receives both directions of every real parent-child edge and retains its own native GCN self-loops, graph normalization, attention pooling, graph-token attention, per-node cross-attention and single set gate. The two layers have width 32 and four heads, with the author's attention pooling and dropout 0.1. Within each set, there is no invented root, spanning-tree reduction, node correspondence or positional embedding.

The observed frontend reuses the actual TreeLoom bank's tuple19 allele/donor-frequency lookup and site-pooling methods. It exposes only known pure-reference labels, unknown-query indicators, observed ages, node times/root/sample flags, and observed branch geometry/support. Incoming branch features become node channels because native GraphSetConv has no edge-attribute argument. The bank field named branch_support_true is aligned observed concordance, not true query ancestry. The frontend and LAI head are trained from fresh seed 20261024. No pretrained TreeLoom or GST checkpoint is loaded.

This context differs materially from TreeLoom's full-genome identity memory and genomic GRU: GST attention is restricted to each disclosed eight-tree set. Every tree still traverses the model, including sets with no sampled emission. Such sets contribute no supervised loss. Windows with focals accumulate their summed crossentropy divided by that parent's fixed sampled-row count. One optimizer step follows each complete parent; 30 passes over three TRAIN parents give 90 updates. AdamW uses learning rate 0.001, weight decay 0.0001 and gradient clipping at 1. The fixed final epoch is selected. These LAI settings are declared new-run choices, not a source-native GST training schedule. Any later tuning requires separate held-out validation; TEST is not a tuning set.

The dataset streams native eight-tree banks through the same observed encoder used by TreeLoom. It does not create a large persistent bank archive. Eight spawn workers prepare CPU windows, each with one Torch thread; the production route pins batches for transfer. Prefetch is one window per worker. Worker data contains observations and canonical focal indices; TRAIN targets remain in the main fit process after all TRAIN observations are authenticated. All workers are explicitly shut down on completion or exception.

The complete-set operational bounds are 262,144 nodes and 16,384 retained SNPs. An oversized complete set fails; it is never cropped or redrawn. Proposed host memory is capped at 128 GiB including eight replicated observed states and temporary banks. Fit and prediction each have a finite 24-hour wall allowance, with 64 MiB and 32 MiB output reservations. The 12 GiB initial GPU headroom is an admission estimate, not an allocator cap. The authorized full-device policy applies. These production estimates have not been measured on a full AP parent.

The final synthetic CPU check passed actual native GraphSetConv forward/backward, node and graph permutation checks, all-parameter finite gradients, and exact checkpoint restoration. It exercised eight real preparation workers, all exiting zero and absent afterward. Coverage was 17 trees, 96 real edges, 16 SNPs and 32 canonical focal IDs, including a final one-tree set with zero SNPs, isolated samples and no focals. CPU smoke did not exercise pinned CUDA transfer or open actual AP data or TEST truth.

The ready inert DAG is `configs/benchmarks/paper_gst_lai_8_20261024_final.json`. It contains the full fit, all-five-TEST prediction and a separate common scorer. The scorer predeclares CNN, retained Dense control, TreeLoom and GST-LAI-8 for every TEST parent before truth can be opened. CNN products are bound to actual completed receipts. TreeLoom remains an explicit external prediction dependency for ROOT to bind. GST predictions use the existing canonical native-six schema, exact registry references, all raw probabilities and original example IDs.

Source, model, preprocessing and frozen feature identities are pinned in the DAG and model specification. Synthetic weights and fixture directories are scratch evidence; only source, configuration, compact receipts and reports need to enter Git. No full GST fit, CUDA allocation, actual TEST truth access or GST score has occurred in this preparation.
