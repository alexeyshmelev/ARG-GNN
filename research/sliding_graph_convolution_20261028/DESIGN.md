# Sliding convolution over complete genealogies

28 October 2026. Separate source/CPU research only. No learning, GPU use, labels, baseline changes or dataset changes.

## Recommendation and actual difference

Keep a **branch-overlap joint convolution** as a narrowly defined alternative for later qualification, not as a demonstrated new general convolution. The useful hypothesis is that ancestral branches sharing sampled descendants at the same ancestral ages provide better local cross-tree context than three selected age cuts. The implementation below is an isolated operator, not a trained ancestry model. A generic stack of trees joined at persistent leaves is already covered by spatiotemporal GNN prior art.

The frozen `research/redesign_20261028/architecture/window_model_frozen_v1.py` computes a complete upward/downward cavity encoder, exchanges leaf and selected-cut summaries, then computes another complete cavity encoder. This candidate instead uses native branches as cross-tree carriers at **all overlapping ancestral ages**, and simultaneously updates native tree edges, same-leaf edges and branch-overlap edges in every joint graph layer. A complete tree encoder may initialize these layers, but no second sequential cavity sweep is obligatory. It is not a code-equivalent acceleration of the frozen model. Nor is its correspondence a fundamentally different mathematical family: exact branch overlap is an integral of the same shared-leaf partition incidence used by cut transport.

## Coordinates, observations and correspondence

Genomic coordinate x is physical bp by default. A recombination map g(x) is a distinct coordinate in Morgans, and branch age a is in generations. Do not subtract these units or call a topology change an inferred recombination event. Genetic-distance kernels are a later declared alternative. Map plateaus require a separate bp rule if observations there are to receive nonzero mass.

At each selected coordinate x_t, retain the complete inferred rooted tree T_t with native nodes, parent map, observed dates and the common sampled-haplotype roster S. The implementation requires explicit unique stable sample IDs as routing metadata and verifies the same ordered IDs and sampling ages across trees. These IDs never enter learned feature channels. An occurrence (t,u) carries the finite branch above native node u, I_tu=[age(u),age(parent(u))). Roots have no finite branch above them and receive native-edge messages but no branch-overlap message. All nodes remain in the graph, including zero-length branches. Descendants D_tu are stable sampled identities. Renaming any internal node must only permute computation. No inter-tree equality is inferred from its integer ID. The toy implementation accepts terminal samples and forests and explicitly rejects sampled interiors; a production adapter must add them correctly before claiming that support.

For two branches u in target t and v in source s, define

    M_ts[u,v] = |D_tu intersect D_sv| * eta(I_tu intersect I_sv)
    m_t[u]    = |D_tu| * eta(I_tu)
    B_ts[u,v] = M_ts[u,v] / m_t[u], if m_t[u] > 0, else 0.

The implemented ancestral measure is eta([a,b))=b-a. A frozen nonnegative density such as exp(-a/tau)/tau can later emphasize recent ages, but changes the operator. For each sampled identity, intersect its two sorted leaf-to-root branch paths and accumulate each overlap. The result is exact for these supplied dated trees and this measure. Each source branch has one hidden state, held constant over its lifetime for this integral. Integrating all overlap ages does not provide independently resolved hidden states at every age. The normalization is asymmetric: a source clade containing every target descendant throughout the target lifetime can receive weight one even if it contains many additional descendants. There is no source-clade specificity penalty. It is a witness average, not an ancestor-match confidence. It is an observed correspondence weight, not a posterior probability of the same ancestor, a migration probability, or ancestry conservation.

At a fixed age, the extant branches partition the samples that already exist and have not reached their observed root. Their incidence vectors yield M by integration. Consequently B is substochastic: its row sum is at most one when the same sample roster and ages are used. Missing mass records unavailable source branch support, chiefly above a source MRCA. It is not silently redistributed to younger branches. Supply coverage as an observed feature in a complete model. The bare prototype returns left/right branch coverage in JointGraph but does not concatenate or otherwise consume it in BranchJointConv. No complete input encoder, ancestry decoder or loss is implemented. Ancient samples do not contribute at ages younger than their sampling date. Roots are never extended indefinitely to invent older ancestors.

Same-leaf edges are a separate exact identity relation. They retain context even when a branch has zero duration or no overlapping source ancestry. Reference labels, cohort and dates may be observed features under the common benchmark policy. Query ancestry and simulated ancestral identities are never inputs.

## Joint convolution

Let H_t contain d-dimensional node states. For each compact genomic kernel k_b(delta), define weights over source coordinates

    alpha_b(t,s) = w_s k_b(x_s-x_t) / sum_j w_j k_b(x_j-x_t).

A zero denominator gives zero messages. This is a conditional average on each side, not absolute distance attenuation: if there is one source on a side, its alpha is one at every distance below R and becomes zero at R. Thus the full normalized operator need not be continuous at loss of its last supported neighbor. A fixed denominator or retained kernel-mass feature would change this behavior, but neither is implemented. Distance affects relative weights only when there are competing sources on that side. The prototype has separate left and right triangular kernels, both with hard support R. Native parent/child relations and same-leaf relations are separate channels. Its branch channel is

    C_b(H)_t = sum_s alpha_b(t,s) B_ts H_s.

Source weights w_s are coordinate quadrature weights, not automatically native tree interval widths. The update is

    H_next = LayerNorm(H + GELU(H W_self
                      + A_up H W_up + A_down H W_down
                      + sum_b [L_b H W_leaf,b + C_b H W_branch,b])).

A_up averages children and A_down selects the parent. L_b uses the same alpha and stable leaf IDs. Every message uses the previous layer state. This is synchronous relational message passing and can be evaluated for all nodes in one disjoint PyG batch. There is no GRU/LSTM or chromosome scan. The module uses nodewise LayerNorm, not batch/window statistics. Negative learned channel coefficients can express changes rather than mandatory smoothing. Positive adjacency weights alone do not make the full learned layer contractive or guarantee boundary preservation.

A layer mixes relationships before its nonlinearity. Several layers permit mixed paths such as native ancestor -> foreign branch -> foreign child. This differs in placement and carriers from one cut exchange between two complete cavity sweeps. It does not prove expressivity dominance over that model or an unrestricted temporal GNN. With identical aligned metric trees and only same-leaf links, the construction becomes an ordinary restricted product-graph convolution. With no cross edges it is a native-tree message-passing network. With cross edges restricted to a single age partition, it reduces to normalized cut overlap. Dense ancestral quadrature converges to branch overlap for fixed branch states and correct integration weights; three cuts are not in general exact.

## Receptive field and sliding assembly

L layers with genomic edge radius R have cross-coordinate dependency at most LR. Within each tree they traverse at most L native edges unless a complete-tree encoder already supplies global context. Merely loading every tree node does **not** guarantee that distant reference evidence reaches a query. Starting from raw node features, shallow layers can be biologically inadequate on deep genealogies. The preferred later comparison uses one common complete-tree initializer in every arm, then the joint layers, and counts that encoder's preparation, depth-scheduled compute, autograd storage and observation-pooling cost. Those costs are absent from the toy timing, and adding them may erase any apparent per-layer speed advantage.

Two honest bounded modes are available:

1. **Deterministic grid with exact halos.** Fix a global bp grid, finite support R, L, and fixed grid-aligned target roster. Process cores plus LR halo; add base-encoder SNP radius R0 if it reads coordinate neighborhoods. Compute loss/output only on uniquely owned core targets. Source base features and normalization must be identical to those in the whole-grid model. At real chromosome ends, truncate the domain and use the same coverage/normalization in both executions. No zero-padding masquerades as an observed genealogy. This gives exact chunk evaluation of the newly defined grid model, not of a continuous all-tree network. A grid can miss short context intervals. Native-interval SNP pooling would add the entire relevant interval's observation extent to the dependency and must not be hidden behind an LR claim.
2. **Strict K focal windows.** Each target has one focal tree plus K-1 deterministically specified or sampled coordinates in a fixed bp support. Build the complete finite graph for that target and predict only its focal labels. This strictly bounds tree occurrences, supports arbitrary focal positions and has no crop-choice ambiguity because the target determines its window. Batch several independent windows as disjoint graphs. It is exact evaluation of this finite-window model, but **not** exact halo evaluation of an infinite/global network. The target-dependent boundary is part of the architecture. Random contexts define a stochastic model; normalized attention and nonlinear multilayer outputs are not unbiased estimates of a dense network.

Never require both every native tree in a fixed physical radius and a strict K bound under arbitrary tree density. Uniform tree-record windows use a different physical context and are not invariant to redundant tree serialization. Coordinate sampling with a preserved attributed tree/observation field is invariant to pure interval subdivision for identical draws. That claim does not cover recomputed SNP pools, changed ages or altered observations. Repeated coordinates may share immutable topology preprocessing, but nonlinear hidden states may only be reused when features, context and stochastic masks are also identical.

Training examples are unique (parent, target coordinate, query sample) IDs. Partition unique focal IDs into disjoint cores, or sample from a declared target distribution with its proper objective/inclusion weights. Context nodes receive no duplicated target loss. At inference, each target has exactly one owner. Optional averaging across context draws is a separately declared predictor, not multiple equally weighted target observations. Preserve the benchmark target measure; source quadrature and target loss weighting solve different problems.

## Efficiency and limits

For K trees, H sampled identities, N total native nodes, S supported neighboring coordinates per occurrence, average ancestral path depth D and E cross edges, validation itself costs O(sum_t N_t D_t) in this correctness implementation. This can be quadratic for long unary chains. The simple coordinate-neighbor scan additionally costs O(K^2). Exact path-overlap construction costs O(K S H D) and potentially O(K S H D) sparse entries. A highly unbalanced tree has D=O(H), so this is not a worst-case linear method. Complete all-pair genomic connectivity gives S=K-1. Hash/canonical cache keys must include dated topology, sampled identity and ancestral measure. Learned states cannot be cached across updates. A bounded grid stencil fixes S. A fixed K bounds tree occurrences, not arbitrary node counts: the usual binary terminal-sample tree has 2H-1 nodes, whereas unbounded unary chains need an explicit representation-size limit or measured node-budget batching that preserves each selected tree. Zero-length and unary nodes remain native hops, so unary subdivision invariance is not claimed.

After preprocessing, one layer costs O(c N d^2 + E_total d) with a fixed relation count c, using node transforms before scatter. Persistent node/adjacency storage is O(Nd + E_total). The current ordinary PyG edge_index gather and weighted message implementation additionally materializes O(E_relation d) forward temporaries, with peak at least the largest relation and further retained O(E_total d) messages/activations during autograd. A fused sparse matrix kernel would need separate qualification before claiming lower message-memory use. L layers multiply gradient storage. Materializing a full N^2 adjacency or all sample-pair matrices is unnecessary. One PyG disjoint batch amortizes kernel launches; the Python overlap builder is a correctness reference and may dominate the loader. Cache structure once per actual tree pair where safe, or replace the path walk with a compiled/vectorized routine only after profiling. CPU fixture timing is not training throughput, real-tree sparsity, GPU fit or ancestry accuracy.

The main efficiency risk is that the frozen three-cut factorization already moves O(K H) witnesses per scale and avoids explicit branch pairs. Richer continuous-age connectivity may cost more without improving information. Do not exchange several depth-scheduled sweeps for a larger adjacency and call it faster without measuring preprocessing, data transfer, forward/backward, and convergence together.

## Biological hypothesis and rejection criteria

Shared descendants across overlapping branch ages can convey whether a query's recent or older genealogical neighborhood persists through nearby genomic coordinates, without declaring anonymous ancestors identical. Local genealogy errors or limited sites may then be disambiguated using nearby evidence. Failure is equally plausible: relatedness is not ancestry, deep clades mix sources, inferred dates are noisy, reference imbalance distorts witnesses, and smoothing can erase true short tracts. The raw overlap is continuous in small date shifts, but row normalization becomes sensitive when a branch duration approaches zero. Different inferred MRCA dates also change branch coverage, so the model may learn a dating or missing-support shortcut rather than helpful foreign ancestral information. Coverage-stratified diagnostics and independent dating/noise shifts are needed. Zero branches use the explicit zero policy; they are not divided by an arbitrary tiny epsilon. Tree topology changes need not be continuous in this representation.

A later root-registered comparison should share observations, initializer, focal ownership, genomic coordinates, optimization and parameter budget: same-leaf joint convolution; branch-overlap joint convolution; branch overlap with stratum-preserving shuffled sample alignment; and the frozen selected-cut model with comparable optimization. A finer finite-cut approximation with matched cost tests whether integration itself helps. To attribute a gain to correspondence versus scheduling, add a crossed comparison: selected-cut versus branch-integrated correspondence under both a single-exchange schedule and repeated synchronous joint layers, with the same complete-tree initializer and decoder. Comparing only the frozen schedule to this new schedule confounds these factors. Source-clade containment/size and dating/root-coverage strata should be reported to expose nonspecific or missing-support shortcuts. A branch-age or genomic-distance null needs its own independently trained arm if a causal mechanism claim is made. Measure NLL, class recall, boundary F1, short-tract recall and false switches as well as accuracy. A gain only from erasing short tracts rejects the intended biological benefit. Development remains TRAIN/independent VAL, with no TEST-driven selection.

**Decision:** useful as a falsifiable specialized architecture candidate, genuinely different in carriers and layer scheduling from the frozen implementation, but not a new general 3D convolution and not yet proven preferable. Its strongest mathematical feature is an explicit, age-resolved correspondence with exact toy checks. Its weakest point is that this is a continuous extension of known cut-overlap transport with an unmeasured cost-benefit ratio.
