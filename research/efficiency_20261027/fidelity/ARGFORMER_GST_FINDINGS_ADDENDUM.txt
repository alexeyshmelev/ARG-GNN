ARGformer executable and configuration semantics
1. main.py throughput counts padding tokens by default unless count_padding_tokens is disabled. A reported tokens/second figure therefore needs its denominator stated. restart_override changes learning rate, weight decay, scheduler and microbatch configuration; it is not exact continuation.
2. The contrastive balanced sampler draws with replacement. Multiple ranks use the ordinary distributed sampler despite the balanced option. Training load_weights_only=True is model initialization, not optimizer continuation. Class-weight lookup refers to cfg.train_loader even though the builder receives cfg.model; exceptions fall back to uniform weights. This is an observed author-path behavior, not permission to change the original benchmark.
3. embeddings.py defaults to a 10000-row CLI cap. Requested split streams may be randomly interleaved, while output stores only the split-name list rather than each row's split. The caller must preserve the source ARG, split and node namespace; a complete export requires disabling the positive cap. The explicit include_splits route retains final partial batches; default loader behavior can retain its configured drop/shuffle choices.
4. aggregate_embeddings.py assumes already-unique full paths from one shared ARG node namespace. It averages paths equally within each haplotype, then haplotypes equally within each individual. This is not physical-span weighting. It verifies mapped haplotypes are covered but does not establish path uniqueness or disambiguate reused node IDs across independent ARGs.
5. The active FlexBert route is unpadded RoPE attention, pre-normalization, GELU MLP, RMSNorm, token embeddings without learned position embeddings, with a final norm. Native MLM uses twelve layers, sliding_window=128 and global_attn_every_n_layers=3: layers 0/3/6/9 are global; remaining layers use a symmetric 64-position window. Native contrastive configuration leaves the sliding window disabled. These are different computation graphs, not interchangeable performance options.
6. src/flex_bert.py constructs a base pretrained FlexBertConfig and then sets overrides with setattr. This bypasses the constructor's later validations: for example, the native twelve-layer/every-three MLM setting would fail the constructor's (layers-1) divisibility guard if passed directly. A refactor that moves those overrides into the constructor can change or reject the historical run.
7. Unpadded RoPE attention chooses FlashAttention3 when available for global layers, otherwise FlashAttention2 when enabled. Float32 QKV is explicitly converted to bfloat16 for FlashAttention and the result converted back. The external precision=fp32 contrastive setting therefore does not guarantee entirely FP32 attention arithmetic. The fallback SDPA route can include padding if use_sdpa_attn_mask is false; local windows are not supported in that fallback. Backend availability, attention-mask policy and versions must be frozen for fidelity.
8. Nonzero attention dropout is passed directly to FlashAttention2/SDPA rather than gated by module training mode, while the FlashAttention3 call omits dropout. Native YAML attention dropout is zero, so this latent configuration-dependent difference is inactive in those native configurations. It should not be generalized into a claim that every evaluation config is deterministic.
9. Rotary positions and inverse frequencies are built in FP32 before conversion to QKV dtype. Position index resets follow packed sequence boundaries; arbitrary path concatenation or truncation changes positional and attention context. The native full_megatron initialization scales output projections by depth and is not an ordinary default initialization.
10. Generic FlexBertPoolingHead mean pooling averages the padded sequence dimension without an attention mask. The custom contrastive/embedding paths have their own pooling logic and must be traced separately; this observation is not a blanket claim that the native contrastive path uses unmasked pooling. Optional pretrained model expansion tiles weights and maps layers rather than restoring an identical model; it is not an exact continuation mechanism.

Graph Set Transformer task and timing semantics
1. scripts/timing.py times synthetic Erdos-Renyi graphs with 12-25 nodes, four graphs per set, 32 sets per batch, hidden size 128 and three layers. It prebuilds eight batches on the device, uses ten warmup and fifty timed forward/MSE/backward/Adam steps with GPU synchronization, one seed and fixed model order. The target is all zero and parameter counts differ. Data preparation and host-to-device loading are excluded. Its actual import is models.gst.GraphSetConv despite the docstring's gst_v2 wording. This is not evidence of full-parent ARG throughput or ancestry quality.
2. scripts/atom_mapping.py compares molecule-context DeepSets/SetTransformer pipelines with GraphSetConv broadcast/cross-attention blocks. Default siamese framing sets molecule groups to reaction*2+side, so encoder set context remains within one reaction side; separate learned reactant/product projections supply cross-side assignment scores. Joint framing is an explicit alternative, not a hidden default.
3. Despite the docstring's bijection language, the assignment objective is independent per-product-atom cross entropy and prediction is independent row argmax. There is no Hungarian assignment or uniqueness constraint in this script, so multiple product atoms may select the same reactant atom. Scores are masked to same-reaction reactant candidates.
4. Unmapped product atoms are excluded from loss and atom accuracy; reactions with no mapped product atoms are excluded from reaction accuracy. Atom accuracy weights mapped atoms, whereas reaction accuracy requires every valid mapped atom correct. Parameter equalization is optional and changes hidden dimensions; default equalize-params is none.
5. The script uses predefined train/val/test loader bindings and optional first-K and atom-count filters. Exact chemistry parsing and exclusion of map IDs from features remain outside this addendum because uspto50k_data.py was only inventoried. Do not infer the actual retained support from the runner alone.
6. Adam training selects the strictly best validation atom-accuracy state, with configurable patience and clipping. Nonfinite loss/gradients skip updates. The returned wall time includes training, per-epoch validation and final test evaluation, while model construction/data loading are outside it. This wall time is not a fixed-exposure per-update throughput statistic.
7. Reported Student-t confidence intervals vary training seeds on the same test set. Pooled per-reaction errors repeat the same reactions across seeds; they are not new independent observations. The observed/IID reaction-success concentration ratio is descriptive. A higher ratio alone cannot identify interleaved attention as the causal mechanism, despite the generated report's stronger wording.

Implication for TreeLoom work
These author implementations provide concrete reusable ideas and semantics to preserve. Their generic transformer, set aggregation, graph convolution, pooling and attention components are established prior art. Neither source reading nor unrelated molecular/synthetic timing establishes TreeLoom ancestry preservation, whole-parent feasibility, or the owner's useful-GPU-activity objective. Exact execution changes require the frozen numerical contract; changed architecture requires the predeclared independent-parent predictive acceptance gates with TEST sealed.
