Continuation review, 2026-10-27. Static reading only; no source execution.
- joint_interval_model.py/joint_support.py: zero-masked padded rows still enter the unpacked bidirectional GRU. Padding/chunk geometry can affect valid outputs. cM start-delta resets at every chunk. Grouping uses (shard,node), sorting by genomic interval. Loss ignores -100 and masked rows. GRU dropout is active only with more than one layer. HDF5 loader uses pred_label as fallback label if label dataset is absent: this is not ground truth and must never enter honest accuracy as truth.
- sim/Snakefile: pre-simulation biallelic SNP filter (-v snps -m2 -M2) and MAC threshold default5 apply to entire input panel. Reference/simulation sources are subset afterward. Relate uses observed .haps after ancestral/mask preparation; truth NPZ is durable, MSP derived. PCA pruning is QC only. Sample order derives from merged VCF. Relate accepts optional mask/dist, transversion, coal, consistency, seed; absent coal uses specified Ne.
- commands/infer.py: sample IDs assume Relate diploid alignment node2i/node2i+1, validated by count and reference coverage. Inference restricts to recombination-map overlap and defaults to exclude edge trees. Checkpoint labels/reference populations/geometry override CLI/config. Export requires common interval grid, uses node//2 mapping, probabilities at interval midpoint for FB and last interval right-inclusive marker count for MSP; scoring remains half-open. Export support convention must not silently become scoring convention.
- final_test_metrics.py/jackknife.py: native scorer intersects the two haplotype interval partitions, counts SNP truth inside half-open intervals, reports actual/full coverage separately, maps classes by ancestry name, computes squared Pearson correlation for probability diploid dose, and normalizes confusion rows by TRUE class (contrast AP native predicted rows). Variant cap is prefix truncation. Native uncertainty aggregates sample_id.haplotype across shards and prefers ADMIX haplotypes; not independent whole-parent paired uncertainty. Multiple reference files per invocation are rejected. Never infer calibration from dose r-squared: it is insensitive to affine dosage distortion and loses sign when squared. Joint auto-mode always uses GRU.
- run_joint_inference.py: refined probabilities/label/confidence are appended to copied input datasets and metadata; raw and refined labels coexist. Evaluation must select intended dataset explicitly.
- export_torchscript.py: scripts, freezes, then optimize_for_inference. Printed parity difference is before freeze/optimization and has no pass/fail tolerance assertion. Do not count author export success as proof of optimized full-input equivalence.
- run_inference.py: only fast backend accepted; incremental rejected. Reference/query overlap merely warns in verbose mode, not a hard anti-leakage guarantee. Optional haplotype cap samples individuals as haplotype nodes and can split diploid pairs; must remain zero for full paired coverage. Optional feature transfer defaults fp16, distinct from model math precision. debug_drop_partial_batches is accepted by the public call surface but unused (_debug_drop_partial_batches) in the current native fast worker; it does not prove a tail was dropped. Any actually active tail dropping in an alternative route would violate full coverage. HDF5 shard identity must be preserved; TSV truncates floating endpoints and keys only on interval, so it cannot be canonical multi-shard parity evidence.
- utils/tsv_io.py truncates metadata ages via int(float(age)), whereas native tree node time quantization uses round. Preserve path-specific conventions; do not silently normalize them into a new age model.
- flat_row_merger.rs requires bit-exact adjacency, matching signature and optional label; flush strips labels from emitted ExtractedBatch. interval_emitter.rs older path checks signature/label but no explicit adjacency. Even full-signature interval merging changes GRU sequence and cM context, so it is not exact joint-model inference. Keep merging disabled for the baseline.
- guides/hgdp_1kgp.md is a tutorial with modern 20-per-population AFR/EUR/EAS chr22 data, not the paper ancient European roster. It explicitly warns validation-test fallback is optimistic after early stopping. Template has one 30-generation 0.34/0.33/0.33 event and 15-reference model; it is not evidence of the paper simulation parameters.
- fast_lca/engine.rs: every local tree rebuilds target ancestor closure and sample-reference raw distances; reference-reference cache invalidates per tree epoch. Selected nearest references are chosen from uncapped row-relative time distances. Final matrix is directed: each entry uses row node time, log2(1+absolute difference), floor by integer cast, cap; missing LCA gets cap and diagonal is zero. Linear path casts difference to u16 before cap, so values above65535 wrap: retained author behavior, not corrected here. Matrix symmetry is not a valid invariant for temporally different samples. Edge-tree exclusion removes first/last whole trees; map-excluded trees can count as processed while emitting no rows. Native max_count is checked after whole-tree buffered rows and can overshoot, so count assertions need actual emitted rows, not configuration.
- hdf5_writer.rs: all optional probs/logits/final-layer arrays use u16 fp16_bits storage, including fp32-transfer mode. Metadata endpoint f64, shard/node/labels i32, confidence f32. Finish message is required; disconnected writer removes incomplete output. Buffered progress counter is not guaranteed disk-flushed rows. Lossless compression can change bytes without changing arrays; scientific parity compares decoded arrays plus metadata.
- npz_truth.rs and oracle: matches Python floor(left), ceil(right) label window convention, first usable nonnegative label by default, majority ties choose lowest class, purity over available truth SNPs; observed haps filters truth positions. These training-label windows need not equal exact float half-open scoring intervals at fractional boundaries. Author oracle covers selected fixtures only and was read, not executed.
- build_training.rs: reference IDs originate from unsorted Rust HashMap iteration and chunk groups from HashMap::values. A sample_seed does not fix hash order, nearest-reference index tie breaks or archive chunk ordering. Freeze realized references/archives and ordering. Native max_*_subgraphs limits distinct (shard,start_bits,end_bits) labeled intervals, not rows; the engine itself has unlimited count, while the older Python path caps rows. Partial terminal groups are possible. build_chunks sorts start by (start*1e6) as i64. Six complete arrays are materialized and saved directly as uncompressed NPZ. Rust recombination lookup clamps outside the map; Python interpolator uses tiny-rate extrapolation. These are path-specific author semantics.
- inference_worker.rs: try_pin_cpu_tensor unconditionally returns an error; startup disables pinned memory. Configured nonblocking flags/staging slots do not demonstrate actual GPU overlap. Slots rotate sequentially. forward/post times are unsynchronized host elapsed times, not device kernel duration. A possible stale pinned-memory local exists during fallback, but no operational impact was tested.
- sample_iterator.rs legacy backend: nearest refs use integer-cast log distances when log mode is enabled, unlike raw uncapped ranking in fast. Short reference pools pad with sample/PAD rather than fast shared-selection duplication. swap_remove(0) is described as FIFO but produces first then reversed tail ordering. _backend_name is ignored. No cross-backend equivalence is established.
- ancpath_incremental/src/engine.rs: deprecated path stores all owned edge diffs; touched descendants use new-tree sample lists. Equal moved-root tags skip pair recomputation, multiple-root tags force it. On-demand ref-ref caching is epoch-bound. Top-k refresh gate uses dist < kth_dist or already_selected, which can miss an equal-distance newcomer that should win an index tie; this is an untested static concern. Its linear transform caps before the u16 cast, unlike current fast. Author unit fixtures were read but not run. This primitive distance cache is not learned-state reuse and the released public fast workflow rejects this backend.
