### Q: source and numerical qualification before new fitting

No biology target arrays are needed for Q. Proposed future checks use hand-constructed observed fixtures and explicit bounded sources. They do not redo H011's unchanged illustration. Each has a new condition: finite impulses, a new wrapper, shifted sampling, or units.

1. `bio_mc_v1_finite_impulse_dc_diag`: constant two-query SPD M-matrix, at least two unequal anchor sources, finite domain and off-anchor outputs. Compare full action, raw diagonal and gain-matched diagonal in numerator and ones mass. Independently verify continuous-forcing DC equality, then quantify finite response disagreement including the anchor self term and a switching two-hold case. Use the same rates, sources and masses. This labels the confound rather than pretending to eliminate it.
2. `bio_mc_v1_unit_equivalent_action`: canonical z=bp/2Mb, then z'=2z. Set generator rates/damping to one half, masses to twice, and complete source/mass vectors to one half. For S=q-lambda*CQR*r this requires the q coefficient and query ones coefficient to become1/2 as well as lambda'=lambda/2. Then each weighted impulse and propagator is preserved. Simply changing coordinates and rates in the frozen model leaves the q/ones coefficient at1 and changes reference weighting. Qualify the complete action at every layer before describing a unit-equivalent wrapper as invariant.
3. `bio_mc_v1_resolution_layouts`, `bio_mc_v1_quarter_cell_grid`, `bio_mc_v1_tile_shift125kb`: qualify counts16/64, y_a=left+(a+0.75)h with unchanged per-cell mass h, and a125kb-shifted250kb partition with clipped end tiles. Preserve the original100bp output lattice, coverage mask, sample mapping, plain/age normalization and original2Mb units. Every readout remains exactly once. Grid-offset and tile-shift wrappers are absent today.
4. `bio_mc_v1_pointwise_depth_contract`: prove that the added second block has no cross-query contextual state, cross-coordinate message or impulse scan, all added parameters are active on a nondegenerate fixture, total count10,420, and existing readouts cannot modify sources.
5. `bio_mc_v1_order_positive_negative`: pair non-reflection-related permutations of unequal operator-duration/source pairs with exactly the same coordinate-free bag. For a positive target, inject a bounded tagged signal at query1 before an intermediate switching path and predict its arrival at query2, with no target-derived readout feature. Choose independent held-out constructions and ensure the target actually differs across the pair. For a negative target use a permutation-invariant weighted source mean plus prespecified independent noise, or a graph-local target whose sufficient inputs are available identically to every model. Use common fits/budgets and enough examples to estimate the positive contrast and negative false gain. This is a falsifiable synthetic mechanism diagnostic, not ancestry evidence or a novelty theorem. No task is generated in this handoff.

Independent dense float64 action/source checks should use the already inspected core oracle tolerances around3e-12, and full-network equivalence around3e-11, unless a new wrapper's documented conditioning justifies a separately frozen tolerance. Source masks/ones identities should be exact where possible. Float32 learned executions need a separately recorded tolerance and rejection counts. Nonpositive/nonfinite mass and input failures remain explicit failures with no hidden floor, jitter or alternate geometry. Current tests assert these properties. This plan has not rerun them.

### C: two-condition depth block, with optional explanation checks

A concrete pointwise design reuses the second layer's q/r projections, mixture, gate, message projection and norm. At each query coordinate separately, form the usual instantaneous source/mass using its original fixed observed reference embedding and plain QR. Form the branch-normalized signal S_s/m_s, multiply by d_s/(1+d_s), mix with pi_s and use the usual residual gate. The second block reads only that coordinate's first-kernel query context. ### D: reserved ordering and scope pairs

Do not start D automatically or call the designs implemented.

`bio_mc_v1_plain_d2_bag_generator` would replace changing QQ by its within-tile physical-width average, preserving actual coordinate-placed QR sources and target-local embeddings. Cache the new plain bag eigensystem offline. Global rates make that cache valid. It removes operator switching while retaining source placement and cannot be named unordered.

`bio_mc_v1_plain_d2_unordered_set` must additionally remove source placement from contextual source formation at every depth. One precise option pools the original32 anchor query embeddings and reference forcing/mass pairs by anchor mass into a per-query coordinate-free state, uses the within-tile bag QQ, supplies constant pooled impulses at the same anchor grid, and feeds only pooled updated anchor context into the next layer. Keep target-local embeddings for readout but prohibit them from becoming later sources. Pool reference terms after applying each tree's QR and r map, and pool the matching mass identically. This preserves the sampled source-information set and all-hold geometry bag while removing ordered contextual composition. It changes source pooling and nonlinear feedback as well as order. Hence both generator-only and strict-set arms are necessary for a narrow interpretation. Qualify record/source permutations with preserved pair masses and forbid target-coordinate or numeric-ID features in the set branch. References: H003/H004/H011/H020. Boundary ordered/bag implementations are useful precedents but cannot be silently substituted for these finite-anchor D2 controls.

Both use a query-node head, no CLS parameter/relation bin, the same observed47-field definition, dimensions, optimizer and support. The pair identifies the effect of the combined observation/token restriction in that comparator family, not the necessity of the candidate's whole-tree Kron memory. References: H008/H020. ## Resolution and biological confirmation after development

The first sensitivity pass uses unchanged, sealed selected checkpoints with A16/32/64, the quarter-cell grid and the shifted tile partition. These are inference perturbations on the exact same input/support, not fresh independent biological replicates or equally optimized model variants. Parameter shapes permit anchor-count checkpoint reuse, but constructors/layout bindings must agree. Rate units remain canonical. Compare prediction disagreement, raw NLL, boundary/short-tract errors and cost. Count source-touched holds/span separately from all propagated holds.

A prespecified adequacy proposal is a1 percentage-point minimum meaningful present64 error change, matching the biological benchmark's planning target. If A64 materially changes error or boundary behavior, or grid/tile perturbation exceeds that margin,32-anchor adequacy is unestablished. Refitting one declared alternative on TRAIN/VAL may answer training sensitivity under a new registered condition. It cannot turn a selected A32 checkpoint comparison into a continuum theorem. No numeric adequacy claim is made here.

Freeze the final source/configuration, primary contrasts, seeds, selection history, failure handling and support before independent parents or TEST scoring. The primary utility endpoint is equal-parent present64 physical-span C4 error. Raw NLL remains the development checkpoint criterion and a prespecified secondary mechanism endpoint, with infinities retained. Do not treat windows, sites, trees, haplotypes or optimizer seeds as independent genetic parents. Average or model optimizer repeats within each parent, then estimate paired uncertainty across parents.

The four-parent H020 pilot has only two VAL parents. It supports execution and descriptive development comparisons, not reliable power, final effect estimation or many adjusted mechanism claims. Additional independent development parents are needed to estimate paired-parent variance before choosing final N. Use the existing biological plan's1 percentage-point effect,80% power and familywise0.05 utility contrasts as planning assumptions, not a manufactured powered sample size. Prespecify a small confirmatory mechanism family and an adjustment or hierarchical order separately from the three native-competitor utility contrasts.

Priority robustness conditions are paired cleaned true-observation versus reconstructed trees on common Relate coverage/output support, one frozen demographic perturbation and one reference-age/composition perturbation. Truth trees must be cleaned of census-only nodes/annotations and never supplied through a target capability. If the paired setting changes clipped tile endpoints, anchor placement becomes a second factor and must be aligned or reported. Existing biological docs propose an explicit size/pulse OOD profile and genotype/phase error profile. Those are prospective conditions, not admitted inputs or accomplished validations here.

For interface size, first distinguish readout-only subsetting from a smaller dynamic Q. Readout-only Q8/Q64/Q120 does not change the model and should preserve existing outputs by contract. Changing dynamic Q184 requires a new exhaustive Q/R partition and recomputed reduction/normalization. Unselected non-pure leaves cannot become labeled references. Use deterministic nested actual-query subsets of the same parents, retain mixed64, and explicitly eliminate other non-pure leaves as unlabelled observed vertices or prune them under one frozen rule. These are separate observation/interface interventions. A separately seeded cohort cannot identify query-count effects. Native nearest-reference behavior is not a substitute.

## Novelty and claim limits

No contrast in this plan proves novelty. Positive results could support usefulness of the specified composition. The closest-prior-work table must separately identify persistent sample states, graph dependence in generator versus injection, exact durations, reference grounding, finite source measure, nonlinear depth and serial-subdivision assumptions. Same-source GRU/scalar kernels, existing GraphSSM/GST adaptations and native ancestry competitors answer different questions. A fair MP-SSM or covariance comparator and its biological bindings are still missing. One concrete remedy is a separately reviewed same-boundary/source, exact-duration linear-process/SSM comparator with a fixed homogeneous generator, followed by an explicit MP-SSM adaptation decision based on its equations and access budget.

Inherited mathematics includes Kron reduction, M-matrix positivity, linear-process covariance PSD, spectral homogeneous holds and semigroup composition. The candidate's plausible distinctive scope is the persistent sampled interface with integrated-age electrical equivalence, exact finite physical impulses and repeated normalized updates. It remains a composition requiring predictive evidence and a prior-art crosswalk. The rejected bare low-rank operator H019 must not be reopened as novel without a new precise biological constraint.

A gain under age/full, D2 or reordered inputs does not establish that ancestry is carried on meaningful historical query paths. The concrete remedy is convergence of the block/pointwise/transient/set contrasts with prospectively defined observed-input strata and independent biological effects. Stratify by observed local reference ambiguity, changes in nearest-reference identity/evidence and proximity to tile edges before truth access. Truth-defined short tracts and boundaries are scoring strata only. Show all strata and failures, including cases favoring ordinary smoothing.

Chickenpox's fixed topology cannot identify changing noncommuting operators. Its forecasting specification and causal source/readout checks remain separate unfinished work. No cross-domain start is part of this plan.
