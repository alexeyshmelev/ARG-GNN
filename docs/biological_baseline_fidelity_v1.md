## What a matched comparison means

The current common biological estimand is the true query lineage's population at census350, collapsed to ANA, CHG, WHG and EHG. Some pure observed reference samples are older than350. Every scored query is younger than350. Diploid haplotypes and independent simulation parents are split before extraction.

Scoring uses the same original physical 100 bp centers, bins clipped to observed coverage, exact class-span intersections and all120 query identities. Present64 is the primary stratum and ancient56 is secondary. No purity deletion, target-based support selection, probability floor or outcome-chosen smoothing is allowed. Published real-data ancestry paintings are comparator predictions, never ground truth.

Matched coordinates and labels do not erase differences in native information access, supervision, inference pipelines, training objectives, budgets or selection. These differences must accompany results. A supervised inductive model and within-ARG transductive representation are both applicable, with their deployment requirements declared. Hard nearest-neighbor votes may legitimately have infinite log loss. Preserve that result rather than adding a probability floor to make them resemble a learned probability model.

## Adaptation rule

Mechanical changes preserve the author computation: environment packaging, file format, coordinate/sample joins and equivalent label aliases. Prove equivalence using source checks or a contained parity test.

Task transfers change the panel, source classes, training samples, inference pipeline, downstream readout or budget. Name them explicitly. Check that all required biological information still exists and that original selection/postprocessing is retained where specified.

Changes to layers, objectives, feature definitions, native reference selection or core postprocessing create derived methods. Keep the unchanged author baseline as a separate comparator. Do not rank a substantially modified model under the author's original method name.

## Gating issues and next evidence

The correct connected-sample audit is experiments/results/relate_observed_identity_audit_v1/receipt.json. Every marginal tree has279 connected internal nodes and no internal ID is reused across trees. The earlier preliminary occurrence count included isolated roots and is superseded. A corrected or native-inference condition must have fresh versioned observation provenance, predeclared input adequacy and unchanged author model. Do not overwrite current observed files or rerun unaffected fits blindly.
