## Admission and naming

Each condition must bind the paper version, source commit, raw distribution URL/version, full-file hashes, ordered sample/reference/query identities, coordinate/build/map and preprocessing, simulator/dependency/config/seed recipe, unit of splitting, exact split membership, native model/objective, checkpoint selection, postprocessing and metrics. Unknown fields remain unknown. A source commit or metadata-response hash is not a full dataset checksum.

Use the following distinct labels:

| Label | Evidence required |
| --- | --- |
| `identical_original_raw` | Verified original raw bytes and author split/subset/preprocessing identities. A download from a currently cited collection alone does not establish the exact authors' processed dataset. |
| `author_recipe_resimulation` | Original author simulator and complete versioned configuration/seed recipe, newly generated bytes. State explicitly whether original seeds were supplied. Newly chosen seeds cannot recover original raw data. |
| `released_author_workflow` | Genuine pinned public model and its released protocol. Record any publication/source discrepancy. |
| `independent_confirmation` | Independently frozen parents/subjects or seed streams, matched task, full planned coverage and genuine comparator. Report separately from the author's original split. |
| `task_transfer` / `derived_endpoint` | A disclosed changed task, head, input panel, metric, ontology collapse or postprocessing. Never rename it as original-paper reproduction. |

Every adapter change has a record containing category (`mechanical`, `task_transfer`, `derived`), old/new behavior, reason, source locations, numerical/semantic qualification and affected endpoint. Mechanical changes may relocate outputs, remove external logging, replace removed APIs or stream batches only when model inputs, objectives, order, selection and predictions remain equivalent. Changing an architecture, masking, checkpoint selection, reference draw, sample count, smoothing, scoring subset or split is a scientific change, regardless of convenience.

No training labels or held-out ancestry truth may enter observation, ARG inference, reference metadata, model selection or candidate evaluation-coordinate selection. Preserve genuine native model training even when it differs from candidate invariance or compute assumptions. Log transductive access and compute. Missing original architecture or hidden splits cannot be replaced silently.
