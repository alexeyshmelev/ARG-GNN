# Model lineage

TreeLoom's **final architecture selection for benchmarking** is H050 `stable_leaf_memory`. It was selected on reused European development simulations. Independent benchmark validation remains unfinished. The [current scoreboard](../research/current_scoreboard.md) gives scores and present execution status. The [experiment ledger](../research/experiment_ledger.md) and [historical research snapshot](research_history_before_benchmark_refactor_20261018.md) retain the complete decisions, failures and receipts. This index adds no experiment or result.

The selected model consumes observed whole trees, allele/reference evidence and genomic spans. A first upward/downward tree sweep supplies local clade-change and own-state residuals, plus memory along persistent sampled haplotypes. A second sweep uses the same tree-message parameters. Leaf-aligned context then enters a one-layer bidirectional GRU and a direct ancestry classifier at native tree holds. See the frozen [European implementation](../research/reviews/frozen_benchmark_training_ready_20261017_v1/european_frozen_treeloom_v1.py), [American task binding](../research/reviews/frozen_benchmark_training_ready_20261017_v1/american_full30mb_frozen_v1.py) and [maintained adapter](../src/arggnn/benchmarking/treeloom.py). Task-specific input/output dimensions do not select a new architecture. Execution corrections preserve these equations; full-size GPU efficiency remains unmeasured.

The recorded weight lineage is **TreeLoom-Base (H038) → TreeLoom-Clade (H042) → TreeLoom-Local (H045 own-state) → TreeLoom (H050 stable-leaf memory)**. Each stage added 960 whole-parent updates, reaching 3,840 cumulative updates for the selected TreeLoom checkpoint. TreeLoom-NoMem is H050's matched continued-training control, selected at its earlier pass 20. Thus developmental score increments include additional optimization and are not isolated architecture effects. The [model-name and training-lineage bindings](../research/reviews/paper_fig_naming_revision_20261016_v2/model_names_and_table_bindings.json) preserve exact identities.
