## Executable boundaries

Running `python -B -m arggnn.anchor_parent_producer_v1` verifies the source/configuration/review pins and reports source-only status. It imports no Torch and opens no dataset input.

`--metadata` requires exact source, configuration and binding digests. It reads only the bound original prepared/observed JSON manifests and the selected parent's original/derived observed rosters and completion JSON. It checks producer/configuration provenance, the complete original sampled-ID role joins, explicit tree IDs and inventory, all eight tile records, original physical support and retained readouts. It never opens the native tree, grid NPZ, graph or bank tensor files. It provides no array admission.

`--qualify-observed` requires that same explicit binding, `observed_only_authorized=true`, declared CPU headroom and `CUDA_VISIBLE_DEVICES=` before Torch import. This is a separate root-owned observed qualification, with no model or optimizer instantiated. It reads only the selected original observed/native tree, observed fixed grid, observed provenance and eight unchanged graph/bank artifacts. Truth/oracle/TEST paths are rejected before opening. The root binding template remains unauthorized.

The observed qualification verifies native tree indexes through original tree iteration and compares each tile's serialized graph with `biological_candidate.pack_observed_tile` applied to that native source. It verifies the original full bank fingerprint, uses the unchanged `biological_candidate.load_bank` on CPU, and regenerates the ordinary plain leaf interface and Q/R response using the original `kron_interface` functions. Original feature/response inputs and IDs are compared exactly after the original float32 conversion. This regenerates qualification inputs only; it does not persist a new cache or reconstruct/replace the cached age operators. A failure remains a failure rather than weakening equality or support.

## Assembly and numerical integration

`assemble_parent_v1(verified, geometry)` takes the verified original source inputs. Eight unchanged cached layouts retain 32 anchors each, their exact weights, every cache-graph occurrence and explicit chronological original tree IDs. Native namespace includes the original tree file digest. Per-tree fingerprints include parent/source namespace, explicit leaf/Q/R IDs, original47 selected feature columns, leaf rows and plain normalized-response rows. Tile clipping coordinates are excluded from the input fingerprint. `stitch_context_v3` owns the exact256-anchor union and original target mapping, with float64 physical coordinates normalized by2,000,000bp.

Both age and plain arms use identical `bank.leaf_x` and plain `query_cache.normalized_response` encoder inputs. Only the fixed kernel operators select age versus plain. All280 leaves, Q184/R96, actual120 and latent mixed64 remain intact through the original loader. No target is an input feature.

`original_model_optimizer_v1(geometry, seed)` constructs the unchanged original47-feature, hidden32, two-layer encoder/two-layer kernel model with latent8, three scales, per-tile32-anchor guard, `(5.,20.,80.)` initial coupling, damping1, full coupling and log rate parameterization. AdamW retains learning rate0.001, ordinary weight decay0.0001 and excluded rate/mixture decay0. Seeds are101/202/303. Supported numerical qualification dtypes are float32/float64.

`forward_parent_v1(assembly, model, mode=..., checkpoint_blocks=True)` sends complete inputs and all readouts through `parent_context_v3`, with exact explicit leaf IDs and event blocks64. It returns full logits and the connected latent/layer contexts. The original per-tile model is untouched. No source, carry state, layer numerator/mass or output is detached. The caller can use the unchanged `matched_parent_step_v3` for forward-only loss callbacks, one aggregate backward, one norm1 clip and one AdamW update. Callback gradients remain forbidden, including a manually assigned zero tensor. This module contains no training loop or supervised objective.
