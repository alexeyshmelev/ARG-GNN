## Root input and source contract

`prepare_census_biological_bank_v1` consumes an already decoded observed tskit tree sequence, the serialized whole-observed tensor dictionary, explicit observed sample-role rows, original physical tile/grid coordinates and five source records. It has no file-array loader, truth capability, scaler fitter, native reconstruction executable, optimizer or training entry point. The root's admitted reader must verify the original observed artifacts' actual file hashes before passing these objects. Source records are exactly `native_observed_ts`, `serialized_whole_observed`, `observed_roster`, `observed_grid` and `producer_receipt`, each with a project-relative path and SHA256. These externally verified byte records become part of the certificate. A supplied hash string alone is not proof that an object was loaded from that file.

Observed role rows contain only actual persistent integer sample ID, native sample vertex, declared role, observed age and observed reference class. Native sample vertices must exhaustively equal the tree sequence's280 samples with one-to-one actual-ID/native joins. Default roles are Q120 `query`, context64 `mixed_reference_only`, and R96 `pure_source_reference`, with24 R per observed class Ana/CHG/WHG/EHG. Dynamics are scored plus context Q184. Every Q must be strictly younger than350 and have no reference class. R can be younger, equal or older than350 and is only observed proxy evidence. Native float64 sample ages must equal roster dates exactly. Sample IDs and native vertex indexes remain provenance/gather keys, never learned embeddings.

The serialized input whitelist is exactly `{sequence, labels_in_input}` with `labels_in_input=False`. Sequence fields are exactly the observed `GraphSequence` fields. Extra target, truth, population or arbitrary feature fields are rejected. The pinned source/config checks protect the serialization producer, reference augmentation and both reviewed modules. Observed reference class indicators are permitted panel evidence, rather than target ancestry. Caller role/subject manifests and observed-source lineage still require root byte/provenance admission.

Fixture mode alters only panel counts and is explicitly fingerprinted. The shipped config has fixture mode false and strict280/184/120/96 roles. Toy fixtures cannot be represented as an actual full-panel admission by suppressing that flag.

## Exact native anonymous-interior joins

The pinned producer is `biological_candidate.py:pack_observed_tile`, SHA256 `6b3a25d0e59026cab7189032eb41221feb7d1bdf69e15f6c737a672dfb711dd3`. It serializes each original marginal tree in native postorder, with all graph rows concatenated in physical tree order. Stored `node_ids` expose sample native IDs, while anonymous interiors use−1. Their−1 values, equal ages, equal descendant sets and equal F47 rows cannot independently identify an interior.

For every overlapping original tree, the adapter traces the ancestor union from all280 declared native samples. It verifies that pinned native postorder contains exactly that union, with one connected sampled-leaf tree. Isolated non-sample nodes belonging to other marginal trees are excluded. Their counts are recorded. Every original tree intersecting the tile is retained, including holds with no readout or anchor. No topology/clade deduplication or skipped tree is permitted.

Exact row identity is **the pinned producer's native postorder position**, backed by the same certified native tree/source records and full serialized parity. From these positions the adapter exports native vertex by source row, per-tree source-row ranges, actual/native/source sample joins and original native tree indexes. No anonymous vertex is matched by age or clade. Numeric native ages and parent endpoint differences come directly from `tree.time`, stored as CPU float64. No float32 encoded time is inverted.

The producer is replayed only on the selected tile's sample-ancestor unions. There is no `(ts.num_nodes,47)` feature table over all globally stored nodes. Work includes the selected native tree rows, stored tile features and fixed reference summaries. It is not memory-free and must be budgeted by the root before actual preparation.

## Full parity before F47 projection or compression

The native replay reconstructs the exact original eight float32 channels: four observed-reference one-hot flags, Q120 actual-output flag, all-sample flag, encoded age and encoded parent branch. The encoded-age and branch transform is `log1p(native generations)/log1p(10000)` cast to float32, as in the producer. It also reconstructs the16 reference landmark descendant flags in the pinned per-class `np.linspace` order, graph IDs, sample native IDs, both directed edge entries in source order, exact physical intervals/grid and native dynamics-query order.

The unchanged `ReferenceFeatureAdapter` then reproduces the existing40 appended source-major summary fields. It operates on the producer's float32 encoded ages. The adapter compares all stored x48 values, dtype, shape and stride, all edges/IDs/graph assignments, landmarks, intervals, positions, query IDs, target graph lookup and window bounds exactly. This occurs before any F47 projection or unary suppression. The handmade serialized round-trip test saves and restores the exact observed tensor dictionary inside project pytest basetemp and checks this join.

Only after full parity does F47 select original columns0–6 and8–47, dropping **only original parent-branch column7**. It reuses the exact stored values, with no new fitted scaler. F47 retains encoded age and TMRCA-derived reference summaries. The original plain/non-age operator condition therefore still has age-derived input features. It is not an age-free feature condition. This adapter does not replace these summaries with native-float64 recomputations, remove further fields or reinterpret their class-major semantics.

The reviewed encoder separately receives explicit native age/type/retained edge-time channels. Native census grouping and donor dynamics use direct float64 dates. Their precision contract differs deliberately from the preserved original float32 F47 feature transformation.

## Anonymous unary policy

Full x48 parity proves that an unsampled interior's source features contain only deterministic observed topology/time/reference summaries from the pinned transformation, rather than an independent measurement. Such a nonroot unary row has no sample/reference/output role marker. The original branch column is already excluded from F47. Its source-derived intermediate feature row is disposable under the declared anonymous-unary model constraint. The checked core then suppresses it, preserving every branching interior, root and sampled leaf. Retained stored F47 remains unchanged, and endpoint durations become additive differences between retained native vertices.

Native postorder can change retained row order when a unary vertex is inserted. Comparisons therefore align retained actual native vertices or gather actual samples, rather than assuming equal row positions between two different serializations. The qualified fixture has two serial anonymous rows with the same stored float32 encoded age and descendant clade but distinct direct native times/positions. It joins both source rows exactly, suppresses them afterward, and preserves retained feature/duration/cut semantics after native-ID alignment. Arbitrary extra information inserted into stored F47 fails full producer parity before suppression.

This does not prove that arbitrary observed unary data can be discarded. A different native source with independent unary measurements needs a separate representation/protocol. Sampled interiors remain rejected under the reviewed sampled-leaves-only contract.

## Canonical original coordinates

Physical intervals and retained center indexes stay in original bp, with one division by2Mb for the supplied layout. Tiles remain the original250kb partitions clipped to common support. The adapter requires every original100bp center `50+100*index` in the clipped tile, in strictly increasing original index order. It preserves native tree indexes and exact contiguous clipped coverage. There is no tile normalization, resampling or outcome-based grid selection. An exact boundary belongs to the right hold, and the final tile endpoint is excluded.

Original physical endpoint values are retained directly, rather than reconstructed by multiplying normalized values. Shared boundary/readout bp values use the same canonical division representation. The frozen compact layout still derives midpoint anchors from normalized bounds. When an intended physical anchor/boundary/readout coincidence yields a different IEEE normalized value under that frozen arithmetic, this adapter **rejects admission**. It does not add an epsilon, silently merge events or modify the reviewed kernel. A handmade translated3200bp fixture exposes this rejection. Actual clipped tiles need the root's collision qualification before numerical admission.

## One source-bound preparation artifact

From the same certified uncompressed native trees, the adapter rebuilds observed-TMRCA donor weights, census memberships, sample-set turnover, fixed anchors and checked forest height/depth metadata. The original F47, native parent/time/sample tables, retained inputs, complete bank, forest, native/source/grid maps, role/config and source records form one fingerprinted certificate. Tensor fingerprints include dtype, shape, stride and bytes.

`validate_census_biological_certificate_v1(cert, expected_certificate_sha256)` requires an externally pinned hash and recomputes the current certificate fingerprint. Changed R dates, F47, donors, cuts, forest maps, source hashes or original-grid joins fail before model execution. The expected digest belongs in the root's independently reviewed immutable-artifact/job record. It must not be regenerated from a changed object merely to make validation pass.

`forward_certified_census_biological_v1` validates that artifact, then calls the unchanged shared `CensusTreeGNNV1`. Proposed, eta0, raw-diagonal and pointwise local use the certified observed bank. The permuted contrast applies its explicit checked global Q permutation afterward while retaining the same certified donors/signals. The runner must freeze and record that permutation across the matched condition. Encoder/source projections/gates/decoder remain the same parameter objects. Scored actual IDs and original readout ordering come from the certified roster/grid.

There is no forward Python Q-by-R MRCA search. Donors are rebuilt once during certification and their bytes are checked through the certificate thereafter. Full CPU fingerprint verification does cost time and touches fixed input bytes. The current wrapper validates on each call. A later immutable-cache admission policy or different verification schedule would require separate root review. No speed/activation-memory result follows from this source interface.

## Prespecified source-only support and numeric protocol

`select_census_numerical_tiles_v1` accepts structural metadata only: parent ID, train/val split, original tile ID and original tree count. The default requires all32 tiles of four distinct parents, eight tiles each, consistent twoTRAIN/twoVAL parent splits. It selects minimum and maximum **TRAIN** tree count before outcomes, tying by parent ID then tile ID. Accuracy/NLL/outcome fields are rejected. Existing metadata or a separately admitted structural pass must provide these counts. No actual tile identity was selected from project arrays here.

After root admission, `collect_census_biological_support_v1` accepts all32 certified tiles and their external hashes. It reports native connected node/edge counts, excluded unrelated nodes, role/date agreement through successful certification, older-reference count, group counts, query-weighted group-size/singleton/opportunity distributions, physical-span-weighted group sizes, and turnover rho weighted by the right hold's original physical width. A boundary itself has zero span, so that right-hold convention is explicit and frozen. It also reports maximum retained height/depth and a conservative source state-copy budget `2*(height+depth+2)*N*d*4` for float32. This excludes other activations, allocator/optimizer/donor storage and is not measured memory.

Limited mechanism opportunity is predeclared at singleton-Q fraction≥0.95 or all measured boundary rho equal1. A single-tree tile has no measured turnover. These flags concern possible mechanism support, not useful ancestry sharing or predictive benefit. All32 actual distributions remain unrun.

The root's next numerical admission starts with those prespecified TRAIN minimum/maximum cells, using identical weights across proposed/eta0/permuted/raw-diagonal/local. Required checks are full native/serialized/source-map parity, direct native donors/cuts/forest, same-weight outputs, source bounds and positive matching mass without floors, actual sample/readout/target-column ordering, VJPs, finite clipped-AdamW behavior and single-tree versus forest output/VJP parity. Only after those pass does an all-tile numerical pass become reviewable. CPU output tolerances remain float64 rtol1e-10/atol1e-12 and float32 rtol2e-4/atol2e-5; VJP tolerances remain float64 rtol1e-8/atol1e-10 and float32 rtol1e-3/atol1e-5. Actual budgets/protocol and the runner require root freeze before arrays are opened.
