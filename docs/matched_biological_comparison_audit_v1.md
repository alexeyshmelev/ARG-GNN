## Biological meaning and limits of census retention

On a correct dated tree, queries sampled strictly younger than350 with MRCA age≤350 share a lineage at census350. That supports common census-source ancestry, not equivalence of arbitrary six historical path labels. The public AP truth code maps BAA Ana/CHG to paths5/6 and other cohorts' Ana/CHG to1/2 [S2]. A C4 census-source smoother cannot silently be reused as a six-path classifier.

`rho=|C_left(q)∩C_right(q)|/|C_left(q)∪C_right(q)|` is a defensible measure of **stability of sampled-query contextual support** [S8]. Its members are persistent sampled haplotype IDs, not internal-node IDs. A persistent sampled ID identifies the same observed phased haplotype across chromosome positions; it does not make its two local ancestral segments one ancestor. Genuine tsinfer node reuse likewise identifies an inferred ancestral segment within that ARG namespace, not a named person or a whole ancestral genome. Equal clades, local integers or ages cannot establish internal ancestral correspondence.

Retention is not a recombination posterior, a true tract boundary or a probability of source ancestry. rho1 can coexist with an ancestry switch or inference error. A support change can occur without a source switch. Values depend on the sampled Q panel; removing/adding context haplotypes changes the constraint even with unchanged focal biology. R at/above350 supplies donor proxy evidence and stays outside the cut partition.

The useful falsification is predictive: proposed versus eta0 tests support-loss retention, fixed global permuted groups tests biological membership, and raw-diagonal/local controls test exchange and genomic propagation with the same whole-tree encoder/projections/decoder. Almost-all singleton groups or rho≡1 limits mechanism opportunity. Horizon300/350/400 and observation-date sensitivity should keep true target census350 in one branch; changing the truth horizon is a different endpoint. Partition diffusion, state propagation, covariance arguments, TMRCA pooling and whole-tree sweeps are inherited. Priority, useful biological constraint, efficiency and GNN novelty remain unestablished [S8].
