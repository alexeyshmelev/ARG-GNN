# European comparison scope and material deviations

| Condition | Primary source | Executable choice | Meaning of the comparison |
|---|---|---|---|
| AP genome length and panel | Supplement: three 200 Mb TRAIN sequences and five more evaluation sequences. Released roster: 476 diploids, nine cohorts | Canonical 200 Mb recipe, all 952 haplotypes, all 686 queries, BAA retained | A new run of the declared biological scenario, with fresh independent seeds |
| AP TRAIN support | Supplement: 10,000 examples from each of five admixed cohorts, 50,000 total across three parents | Per cohort: 3333 per parent plus one remainder rotated across parents | The totals follow the paper. The deterministic integer allocation is disclosed reconstruction |
| AP test support | Supplement: 10,000 GNNs from each of five additional sequences | Exactly 2,000 per admixed cohort per evaluation parent | Each parent has 10,000 total. Cohort allocation is disclosed reconstruction. The released test script instead allocates 10,000 per cohort |
| AP site selection | Supplement: evenly spaced sites. Released script: stride loops with ancestry-dependent acceptance caps and repeated passes | Equal bins of observed retained SNP rank, bin midpoints, deterministic balanced haplotype order, frozen before true labels | Shared support tests both models at exactly the same sites. This does not reproduce the released class-cap sampler |
| AP classifier | Paper describes a CNN. Released training.py constructs Flatten, Dense512/ReLU, Dropout0.2, Dense6/softmax | Execute original model and final compile AST statements. Adam, categorical cross entropy, five epochs, batch32, shuffle, final checkpoint | A comparison against the released Dense classifier. The paper CNN has not been recovered |
| AP sample independence | Released scripts overlap TRAIN and test sequence numbers 5 and 6 | Eight fresh independent parent identities and seed streams | Independent evaluation, with the departure from the released scripts explicit |
| AP native endpoint | Six census-350 paths, including Ana/CHG through BAA | All six outputs retained. Same-site external labels, original sample identities | A four-source collapse is a separately named secondary endpoint |
| AP uncertainty | Paper reports sequence mean and SD without ddof | Equal-parent mean and sample SD, ddof=1, over five independent evaluation parents | New uncertainty is defined explicitly. Matching the printed plus/minus value is not assumed |
| ARGMix model source | April paper archive unavailable. Available release c2481248eb0de5fda659d68f59c51e0e27becd20 | Available TMRCA transformer plus genomic GRU, 15 references, release defaults | A named available-release comparison, never relabelled as the April model |
| ARGMix training settings | Available template: batch16, up to20epochs, lr2e-4, decay1e-4, label smoothing0.1, patience2, chunks1024/stride512 | These values are concrete. Preserve train nearest-reference augmentation, unlimited native chunks and author best-validation selection | The missing old archive does not block running the available release |
| ARGMix biological data | Paper uses 1,611 diploids without BAA, an empirical chr22 map and genotype error0.001 | A separate config records an explicitly different AP200Mb C4 common-data condition with all 476 diploids, BAA, uniform map and zero error | This can benchmark the available model on shared data. It cannot support an exact ARGMix paper-table reproduction claim |
| ARGMix source labels | Current Rust training uses first-SNP truth per interval, without a purity threshold | Preserve that native training objective. Freeze common evaluation SNPs separately for every method | Different native training representations are allowed. Evaluation identities and true coordinates must match |
| ARGMix unresolved paper inputs | Exact age/ID roster, chr22 map identity/domain, error mechanism, perturbation distributions, old architecture/training source | Keep these fields unresolved in the paper recipe | Do not substitute the prospective1611 reconstruction or guess a paper setting |

The native AP data, model and paired scoring stages are concrete functions in `european_sampling.py`, `european_native_models.py` and `european_workflow.py`. The workflow builds a 44-task AP DAG and waits for every method and all five evaluation parents before reading any evaluation truth. True labels never enter observed feature preparation.

`argmix_release_ap200mb_c4_v1.json` freezes the recovered model defaults and names the separate common-data condition. It explicitly requires one fresh validation parent, native frame/archive integration and a declared common coverage policy. It is not presented as an executable completed ARGMix campaign. The AP native-six DAG contains no fake ARGMix stages.

Resource caps are caller-supplied fail-stops, not predicted output maxima. Complete 200 Mb parent fit, Relate output size and whole-parent GPU throughput still require actual qualification. No shortening, filtering by truth, denominator intersection or silent baseline weakening is authorized.
