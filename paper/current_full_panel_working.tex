\begin{abstract}
Local ancestry inference (LAI) assigns genomic segments to ancestral source populations. Genealogies can inform these assignments by showing how a query genome is related to reference genomes, but recombination changes those relationships along a chromosome. We introduce TreeLoom, a neural model that processes every node of an inferred local tree and follows the same sampled haplotypes through the ordered trees. Messages moving toward and away from the root combine evidence across each genealogy. Structural features describe changes between neighboring trees, sample memory carries the history of each sampled haplotype, and a final recurrent network combines genomic context before ancestry prediction. On eight reused European development simulations, TreeLoom reaches $97.08\pm0.57\%$ span accuracy for modern queries, compared with $94.45\pm1.15\%$ for the evaluated ARGMix release and $93.78\pm0.84\%$ for a derived four source AncestralPaths endpoint. These are comparisons of fitted pipelines with different inputs and training, rather than exact publication reproductions. A matched control without added sample memory reaches $97.00\pm0.50\%$ and has higher boundary F1. The results motivate learning from complete genealogies while showing that accurate genomic assignment and accurate tract boundaries remain distinct objectives.
\end{abstract}

\section{Introduction}
Genomes from admixed populations contain segments inherited from different ancestral sources. Local ancestry inference (LAI) seeks to locate these segments and identify their sources. The resulting ancestry tracts can reveal when populations mixed and how genetic material moved between populations. Ancient genomes add a temporal dimension by sampling individuals who lived before, during and after major changes in ancestry. Their interpretation depends on both the relationships among sampled genomes and the continuity of ancestry along a chromosome.

An inferred genealogy offers a direct representation of those relationships. At a genomic position, a local tree connects sampled haplotypes through common ancestors. A query and a reference genome may share a recent branch in one region and a more distant ancestor in another. An ancestral recombination graph (ARG) represents this changing history, and its local trees provide a sequence of related prediction problems. Evidence from the whole tree can help distinguish ancestral sources, while evidence from neighboring regions can help stabilize local assignments.

Existing methods use this structure in different ways. AncestralPaths classifies genealogical paths in analyses of ancient Eurasian ancestry \citep{eurasians2024}. ARGMix combines graph representations with genomic context \citep{ancientancestry2026}. ARGformer learns representations of genealogical paths and supports ancestry assignment through reference retrieval \citep{argformer2026}. These methods establish the value of genealogies for LAI and motivate a question about representation: can a compact model retain the complete local genealogy while maintaining a coherent representation of each sampled haplotype along the chromosome?

This question has a biological constraint. Sample identities persist across local trees, but inferred internal ancestors need not have a reliable correspondence. Reusing an identifier assigned to an inferred ancestor can therefore connect unrelated states. A model also needs to distinguish a change in tree structure from a change in ancestry. Recombination alters genealogy, yet many neighboring trees can still support the same ancestry assignment.

TreeLoom organizes familiar neural operations around these constraints. It passes messages in both directions through every local tree, uses changes in descendant groups to condition a second traversal, and carries a separate memory for the same sampled haplotype across trees. A final gated recurrent unit (GRU) then reads the ordered local representations and predicts ancestry. Sample memory acts inside the tree encoder, whereas the final GRU acts on its outputs.

We evaluate the resulting model on a shared European development endpoint and examine the specific value of added memory with a matched control. The final model has higher measured span accuracy than the evaluated AncestralPaths and ARGMix pipelines. Its gain over the control without added memory is much smaller and accompanies lower boundary F1. The scientific contribution is a genealogy representation and its empirical assessment, with clear limits on what the present comparison can establish. The eight validation simulations have been reused during development, one optimizer seed is available, and an independent test and remaining native comparisons are unfinished.

\section{Related Work}
\paragraph{LAI from genealogies and genetic variation.}
AncestralPaths uses genealogical paths to distinguish ancestry routes that can share the same broad source population \citep{eurasians2024}. ARGMix learns graph representations of genealogical relationships together with genomic sequence context \citep{ancientancestry2026}. ARGformer learns path representations with a transformer and uses a learned embedding for downstream ancestry analysis \citep{argformer2026}. FLARE estimates local ancestry directly from haplotypes \citep{flare2023}. These approaches differ in representation, supervision and prediction unit. Our European comparison evaluates the available completed pipelines on a common output endpoint, with the release and task differences stated below.

\paragraph{Neural computation on changing genealogies.}
A rooted tree provides a natural order for graph message passing. An upward traversal summarizes descendants, and a downward traversal supplies information from the rest of the tree. Genomic recurrence adds a second order, along the chromosome rather than along branches. GRUs provide an established mechanism for combining such sequential context \citep{gru2014}. TreeLoom uses these standard ingredients to preserve complete local relationships and the correspondence between sampled haplotypes. The relevant empirical questions concern how they are organized for LAI and what added context contributes under matched conditions.

\paragraph{Representations of graph collections.}
Graph Set Transformer interleaves propagation within member graphs with context from the surrounding collection, allowing information exchange before a final graph readout \citep{gst2026}. Temporal graph state space models likewise study recurrent state on changing graphs \citep{graphssm2024}. These perspectives are relevant to a sequence of local genealogies. The genomic setting additionally supplies an order, unequal physical spans and persistent sampled haplotypes, which constrain the relationships that can carry information between trees. This connection motivates the representation without establishing transfer beyond ancestry inference.

\section{TreeLoom}
\subsection{Prediction Task and Model Overview}
Let $T_t=(V_t,E_t)$ be the inferred local tree covering genomic interval $I_t$, with physical length $w_t$. Let $q$ index a sampled haplotype and $v_t(q)$ its node in tree $t$. All sampled haplotypes appear in every tree. The model predicts a probability vector $p_{tq}$ over four source ancestries: Anatolian farmer (Ana), Caucasus hunter-gatherer (CHG), western hunter-gatherer (WHG) and eastern hunter-gatherer (EHG).

The inputs are phased observed variants, inferred tree topology and node ages, sampling ages, and known source labels for reference haplotypes. Query source labels are masked. Simulation ancestry is used only as external training supervision or evaluation truth. It does not define the input features, inferred trees, structural groups or prediction intervals.

Figure~\ref{fig:architecture} shows the complete model. An encoder of observed data first initializes the nodes. A complete upward and downward tree traversal produces local context. Structural conditioning and sample memory modify the node inputs, after which a second complete traversal uses the same learned propagation weights. Its outputs for sampled nodes are aligned by haplotype identity across trees and passed to a final genomic GRU and classifier. No tree is reduced to a single pooled vector before query prediction.

\subsection{Observed Evidence and Complete Tree Traversal}
For each haplotype, a genetic encoder summarizes its called alleles relative to observed donor and panel allele frequencies. Mean and maximum pooling within a tree interval produce a local genetic representation. This representation is combined with sampling age and the known reference label when available. Inferred age, status as a sampled node and root status provide features for internal nodes. These features initialize a node state $b_v$. Branch geometry and summaries of agreement between mutations and observed alleles determine message gates.

The upward traversal combines descendant evidence. For a parent $v$ and child $u$,
\begin{align}
m_{u\to v}
 &= \frac{g_u^\uparrow\odot W_\uparrow h_u}{\max(1,d_v)},\\
s_v &= \sum_{u\in\operatorname{child}(v)}m_{u\to v},\\
h_v &= \operatorname{LN}\!\left(
 b_v+\tanh(A_\uparrow[b_v,s_v]+a_\uparrow)\right).
\end{align}
Here $d_v$ is the number of children, $g_u^\uparrow$ is a gate computed from observed features, $\odot$ denotes elementwise multiplication, and brackets denote concatenation. Normalization prevents the summed message magnitude from simply increasing with the number of children.

The downward traversal supplies the context outside a child's branch. For child $u$, the parent context is
\begin{equation}
c_{v\setminus u}=o_v+b_v+s_v-m_{u\to v}.
\label{eq:outside}
\end{equation}
A gated learned transformation maps this context to the child's outside state $o_u$. The outside state is zero at the root. Subtracting the recipient's upward contribution prevents that contribution from immediately returning as evidence from elsewhere in the tree. Together, $h_v$ and $o_v$ represent information below and outside a node. Both traversals visit every node, including inferred ancestors.

\subsection{Conditioning on Local Tree Structure}
We describe structural changes using descendant sets rather than presumed identities of inferred ancestors. Let $C_t(v)$ be the set of sampled haplotypes descended from node $v$. A proper clade contains at least two sampled haplotypes and excludes the complete panel. When a unary chain has several nodes with the same descendant set, we use its deepest representative.

A node's gained flag $g_v$ is one when its proper clade is absent from the preceding tree. Its lost flag $\ell_v$ is one when the clade is absent from the following tree. Flags at the missing sequence neighbors are zero. The flags condition a local residual,
\begin{equation}
\Delta_v^{\mathrm{change}}=
O\!\left[
g_v(Uh_v\odot Vh_v)
-\ell_v(Uh_v\odot Wh_v)
\right].
\label{eq:change}
\end{equation}
The projections have a lower dimensional intermediate space. An additional local transformation acts on clades that occur in at least two consecutive trees,
\begin{equation}
\Delta_v^{\mathrm{local}}=
\chi_v O_l\!\left[(U_lh_v)\odot(V_lh_v)+W_lh_v\right],
\label{eq:local}
\end{equation}
where $\chi_v$ indicates eligibility. This transformation uses the node's own representation. It does not import an embedding from another tree.

These features identify stability and change in the observed topology. Equal descendant sets do not establish that two inferred nodes are the same biological ancestor. The second tree traversal receives $b_v+\Delta_v^{\mathrm{change}}+\Delta_v^{\mathrm{local}}$ together with the contribution from sample memory defined next. It reuses the first traversal's weights and observed gates.

\subsection{Memory for the Same Sampled Haplotype}
Sample memory means history carried for the same sampled haplotype across genomic trees. It is distinct from the final genomic GRU. This memory modifies the internal tree representation before the second traversal.

We cut each inferred tree at a fixed age threshold and group sampled haplotypes by their ancestor at the cut. Samples older than the cut retain their own sampled node. The cut uses inferred node ages and sampling ages, without query ancestry labels. For group $k$ in tree $t$, a learned projection of the sum of upward and outside states at its representative gives a context vector $f_{tk}$. Let $k_t(q)$ be haplotype $q$'s group.

A forward scan carries a state for each haplotype,
\begin{equation}
z^\rightarrow_{tq}
=\rho_t z^\rightarrow_{t-1,q}
 +(1-\rho_t)f_{t,k_t(q)},
\qquad
\rho_t=\exp(-w_t/\lambda).
\label{eq:memory}
\end{equation}
The first state equals its current context vector. A reverse scan applies the same rule in reverse genomic order. The learned positive length scale $\lambda$ determines how much history is retained over a given physical span. A longer interval places more weight on its current context.

We average the two scan directions, average the resulting haplotype states within each current group, and subtract the group's current context vector. A learned output projection converts this difference to a residual at the group representative. The second tree traversal propagates that residual through the complete genealogy. Sample identity remains the link across trees even when the inferred groups change.

The matched control, TreeLoom-NoMem, omits this added memory and retains both complete traversals, local structural conditioning and the final genomic GRU. The phrase \emph{without memory} therefore refers only to the additional mechanism in Equation~\ref{eq:memory}.

\subsection{Genomic Context and Ancestry Prediction}
After the second traversal, a learned projection of the upward and outside states produces a local embedding $e_{tq}\in\mathbb{R}^{d}$ for every sampled haplotype. Alignment across trees is a direct lookup by the same sampled identity. It does not require matching internal ancestors.

A bidirectional GRU with one layer processes the local embeddings together with interval geometry,
\begin{equation}
r_{1:T,q}=\operatorname{BiGRU}
\left([e_{tq},\operatorname{geometry}(I_t)]_{t=1}^T\right).
\end{equation}
The geometry contains interval length and distances to neighboring interval centers. The GRU has hidden width $h$ in each direction. A classifier combines the local embedding of width $d$ with the resulting genomic representation of width $2h$,
\begin{equation}
p_{tq}=\operatorname{softmax}
\left(\operatorname{MLP}([e_{tq},r_{tq}])\right).
\end{equation}
All sampled haplotypes and tree intervals remain present during these computations. Query selection occurs only at readout. Predictions are constant within an inferred tree interval, so possible ancestry transitions are restricted to its edges.

\section{Evaluation Design}
\subsection{European Development Simulations}
The completed European comparison uses 32 training simulations and eight validation simulations, each 2\,Mb long. The demographic formulation is adapted from the released AncestralPaths workflow associated with \citet{eurasians2024}. The panel contains 476 diploid individuals, or 952 phased haplotypes. There are 266 reference and 686 query haplotypes. Queries comprise modern individuals, Bronze Age individuals, Bronze Age Anatolians (BAA), Neolithic farmers (Neo) and Yamnaya (Yam). Simulation identity determines the split before tree intervals, rows or sequence chunks are constructed.

Relate infers genealogies from the observed variants and sampling ages \citep{relate2019}. All completed European pipelines use the common observed panel and inferred genealogies, represented as required by each method. The simulation assumptions and inference parameters are in the supplement. The released Bronze Age roster is only an approximate correspondence to the ARGMix preprint's Post-Neolithic category.

The eight validation simulations have informed repeated model development and checkpoint selection. We therefore describe all results on them as development evidence. Only one optimizer seed is available for each evaluated condition. Intervals, bins and haplotypes from a simulation are dependent observations, not independent biological replicates.

\subsection{Common Scoring Endpoint}
The primary endpoint is accuracy weighted by physical span for the 182 modern query haplotypes. Secondary endpoints cover the ancient cohorts and all queries. All European predictions are scored on the same fixed 100\,bp bins clipped to inferred coverage. Let $m_{iqc}$ be the physical mass of true ancestry $c$ for query $q$ in bin $i$. Span accuracy is
\begin{equation}
A=
\frac{\sum_{iqc}m_{iqc}\,
\mathbf{1}\{c=\arg\max_k p_{iqk}\}}
{\sum_{iqc}m_{iqc}}.
\end{equation}
Each simulation receives equal weight in the reported mean. We give sample SD across the eight simulations in percentage points. This SD describes simulation variation for a fitted model. It is neither uncertainty across training seeds nor a confidence interval.

Accuracy measures the amount of correctly assigned sequence. Boundary precision, recall and F1 assess whether the ancestry transitions are located correctly. Boundaries are matched one to one within 1\,kb. The matcher uses position and does not require the predicted transition to have the correct pair of source labels. Negative log likelihood (NLL) uses the same physical masses and the original predicted probabilities, without flooring or recalibration.

\subsection{Comparator Scope and Matched Memory Control}
The AncestralPaths comparison uses the released dense six output classifier. We sum its six path probabilities into the four source probabilities before class assignment,
\begin{equation}
(p_{\mathrm{Ana}},p_{\mathrm{CHG}},p_{\mathrm{WHG}},p_{\mathrm{EHG}})
=(p_1+p_5,p_2+p_6,p_3,p_4).
\end{equation}
This derived endpoint differs from the native six path task. The paper describes a convolutional classifier, while the executed archive contains a dense classifier. Its bounded replacement sampler also leaves 9,126 requested BAA path six training rows unfilled, with an unmeasured effect on accuracy. The five epoch author schedule is completed and its final epoch is used.

ARGMix uses the current author release, with 15 references and no ancestor inputs. The preprint describes 25 references and three inferred ancestors. The public release does not provide a supported implementation of that earlier input configuration. A panel slot and metadata adaptation allows the released model to process the common roster. The model, training augmentation and native rule for stopping are retained. Eleven epochs complete, and its native validation objective selects epoch nine.

TreeLoom also receives observed SNP features. Methods differ in reference eligibility, representation, supervision unit, effective training diversity, cumulative optimization and checkpoint selection. The common scorer makes their outputs comparable on this endpoint, but does not make their information or training budgets equivalent. Completing an author schedule also does not establish convergence. These are named pipeline comparisons, with no exact publication reproduction or overall LAI ranking established.

The memory comparison asks a narrower question. TreeLoom and TreeLoom-NoMem start from the same trained local encoder, receive the same additional 960 updates and keep all weights trainable. They use the same checkpoint rule. The memory model has 513 additional parameters. Each arm selects its checkpoint independently. Earlier developmental models received different cumulative training exposure and are not treated as component ablations.

The practical implication depends on the intended use. More correctly assigned genomic mass can help estimate broad ancestry patterns, while a fragmented or displaced set of transitions can distort the reconstructed tracts. The memory mechanism improves the former metric slightly in this condition and reduces the latter. The final model name denotes the highest observed condition by span accuracy, rather than a model that wins every endpoint.

Additional matched controls give little evidence that more elaborate exchange between trees solves this problem. Replacing local node conditioning with context from other occurrences of the same clade changes accuracy by only $+0.01\pm0.15$ points. Alternative transport rules for memory also fail the registered practical criteria. These controls are reported in the supplement without conflating them with the differently trained developmental stages.

\subsection{High Span Accuracy Leaves Substantial Tract Error}
Boundary F1 remains low for all three completed pipelines. TreeLoom reaches 18.38\%, despite assigning 97.08\% of the represented genomic span correctly. This gap shows that a small amount of incorrectly assigned sequence can coexist with many missed or extra ancestry transitions. Span accuracy alone is therefore insufficient evidence that ancestry tracts are recovered faithfully.

The model's readout places another constraint on tract recovery: it can change ancestry only at inferred tree edges. True ancestry changes need not occur at these edges or be resolved accurately by the inferred genealogy. Better boundary recovery may require both a more flexible readout and a training objective that rewards transition fidelity. The present results do not establish the effect of either change.

\section{Discussion}
TreeLoom connects two useful views of ancestry. Within a local tree, reference and query genomes are related through shared ancestors. Along the genome, the same sampled haplotype has a continuous sequence of local relationships. Complete tree traversal makes both descendant and outside context available at each sampled node, and genomic recurrence combines that context in physical order. Sample memory provides an additional route for history to influence the tree representation without matching inferred internal ancestors.

The completed comparison is encouraging for this representation, but its strongest claim is descriptive. TreeLoom performs well on eight reused development simulations under a specified demographic formulation. The native comparator pipelines preserve available author algorithms while differing materially from the corresponding publication recipes and from TreeLoom's input and training choices. The measured gap cannot be assigned entirely to a particular neural component. Independent simulations, multiple training seeds and faithful completion of the native comparisons are needed to assess generalization and relative method strength.

The matched evidence is more specific. Added sample memory brings a small mean accuracy gain and reduces boundary F1. Context from the same clade in other trees and more elaborate memory transport also yield limited gains under their matched controls. These findings favor a restrained interpretation of interaction between trees. They do not establish a new generally superior operator, and they suggest that tract boundaries deserve direct attention during model design and evaluation.

The simulated ancient cohorts are also an incomplete model of ancient genomic data. Their sampling history is explicit, but uncertainty in phasing, genotype calls, reference representation, demographic assumptions and genealogical reconstruction can change the information available to LAI. A future empirical validation needs evidence that is independent of the model's own ancestry assignments. A descriptive application of an earlier TreeLoom condition and its counterevidence are retained in the supplement, without treating model output as known mixture fractions.

TreeLoom provides a concrete framework for learning LAI from complete local genealogies. Its present results motivate further study of that representation while identifying a central limitation: assigning most bases correctly does not ensure that ancestry tracts have been reconstructed correctly.

\section{Model and Training Parameters}
\label{app:training}
The genetic site encoder has two hidden layers of width 32. For a called allele it receives donor log frequency features, corresponding availability indicators, panel frequency, site entropy and a call indicator. Eight donor groups combine the four reference ancestries with ages below or at least 350 generations. Allele frequencies use additive pseudocount 0.5. If a represented reference class has no called alleles at a site in an age group, all represented classes in that age group are masked for that site. Mean and maximum pooling are combined with call count, missing pool status and interval span.

The inferred tree cut for sample memory is fixed at 350 generations. Samples older than the cut retain their own sampled node. Tree states have width 32 and local residual projections have rank eight. The memory projection also has rank eight and adds 513 parameters. Its length scale starts at 5\,kb and is constrained to 100\,bp--100\,kb. Residual output projections start at zero. The genomic GRU has one layer and width 32 in each direction. The ancestry classifier receives 96 features, maps through width 32 and produces four scores. TreeLoom has 32,325 parameters. TreeLoom-NoMem has 31,812.

Training minimizes physical span cross entropy over all 686 queries,
\begin{equation}
\mathcal L=
-\frac{\sum_{tqc}M_{tqc}\log p_{tqc}}{\sum_{tqc}M_{tqc}},
\qquad
M_{tqc}=\sum_{i:r(i)=t}m_{iqc}.
\end{equation}
Here $r(i)$ maps a scored bin to its inferred tree interval. Summing target masses within an interval preserves the original objective because the model's prediction is constant there. A complete simulated chromosome is one optimization example.

AdamW uses learning rate $10^{-3}$, weight decay $10^{-4}$, betas $(0.9,0.999)$ and epsilon $10^{-8}$. Gradient norm is clipped at one. The reported seed is 101. The shared initializer is trained over three successive 30-pass stages on the 32 training simulations, totaling 2,880 updates as tree processing and local conditioning are introduced. These successive stages are a training lineage, not matched component ablations. Optimizer moments reset at each stage.

For the final comparison, both TreeLoom and NoMem start from that same 2,880-update model and complete 30 further passes, or 960 new updates. All inherited weights remain trainable. Checkpoints every five passes are ranked by equal simulation modern validation accuracy, then lower NLL, then earlier pass. TreeLoom selects added pass 30, or 3,840 cumulative updates. NoMem selects added pass 20, or 3,520 cumulative updates, while its run also completes 3,840 updates. The alternate memory rules below share the same initializer, capacity and completed budget as TreeLoom.

\section{Comparator Conditions and Unresolved Recipe Differences}
\label{app:comparators}
\paragraph{AncestralPaths.}
The executed archive contains a flattening operation on a $5\times9$ representation, a dense layer of width 512 with ReLU, dropout 0.2 and six softmax outputs. This differs from the convolutional classifier described in the paper \citep{eurasians2024}. The fit completes five epochs with Adam learning rate 0.001, batch size 32 and shuffling. A deterministic seed of 101 is supplied by the adaptation. The final epoch is used without validation checkpoint selection. Modern deterministic compatibility does not establish numerical equivalence to the original legacy execution.

The bounded sampler accepts 5,190,874 of 5,200,000 requested rows with replacement. All 9,126 missing rows are BAA path six examples, amounting to 2.2815\% of requested BAA rows and 0.1755\% of all requested rows. There are 53,214 replacement duplicates. Other cohort quotas are met. The sampler stops after no progress or a bound of 128 passes, so its realized shortfall is a material adaptation whose accuracy effect has not been measured. Genomic training diversity is $32\times2$\,Mb here, whereas the paper describes $3\times200$\,Mb. Completing five epochs does not establish convergence, and training loss is still decreasing at epoch five.

The four source probability collapse in the main text is separate from six path prediction, a retrained four path task, or evaluation restricted to non BAA routes. It must not be compared directly with a published native six path accuracy. Strict NLL is infinite in the present derived endpoint because a true source receives zero probability over 800 query base pairs. No probability floor is applied.

\paragraph{ARGMix.}
The evaluated author release uses 15 references without inferred ancestor nodes. Its transformer, bidirectional GRU and native training procedure are retained \citep{ancientancestry2026}. It uses 1,024-row chunks with stride 512, yielding 21,952 training and 5,488 validation chunks. All 686 queries are available, with no local subgraph cap. Training drops the nearest reference, validation drops none, label smoothing is 0.1 and loss weighting is absent. Source seed 50 is retained. The model uses supervision at the first SNP of an interval and averages overlapping softmax predictions arithmetically.

Its native selection objective is the smoothed, masked and unweighted mean validation batch loss. The selected epoch is nine of 11 completed epochs, with patience two and a 20-epoch cap. The external span scorer does not replace this inner selection rule. Its preprint's 25-reference and model with three ancestor inputs is not recovered by the current release, whose supported loaders and extraction reject ancestor inputs. A current release run with 25 references would still have zero ancestors and would be a separate sensitivity condition. The original model, exact reference eligibility, checkpoint and publication evaluator remain unresolved. Differences in the observed panel, map, error process, training diversity and prediction support also remain material.

\paragraph{American comparators.}
A separate American benchmark uses a 30\,Mb simulation with 600 reference and 1,000 query haplotypes from EUR, EAS and AFR sources. Native FLARE calls score $98.0100\%$ accuracy and $97.7151\%$ macro F1 on 10,000 predetermined focal records from one validation simulation. This metric counts focal records rather than physical span and has no between simulation SD. It therefore cannot be compared numerically with the European span endpoint or establish a comparative ranking on its own.

The completed FLARE condition uses author release v0.6.0 with native defaults: minimum minor allele count 50, minimum minor allele frequency 0.005, expectation maximization enabled, ten generations, ancestry proportion updates disabled, array mode disabled and seed $-99999$. Native filtering retains 27,558 of 228,477 observed markers. The evaluator uses original hard ancestry calls at the nearest native marker, with midpoint boundaries, on all 10,000 fixed focal records. It does not score a filtered subset chosen after the outcome. All prediction identities and coordinates are checked before private truth is opened. This focal score from one simulation supplies no estimate of between parent variation.

ARGformer's completed American ancestry pipeline remains unavailable. Its published PCA/clustering classifier and nearest reference retrieval are distinct downstream routes \citep{argformer2026}. Exact clustering, class mapping and American retrieval settings are not recovered. The prepared route retains the author release's learned normalized embedding and nearest reference retrieval of the nearest reference as a disclosed reconstruction. The paper states contrastive temperature 0.05 and inverse frequency anchor weighting, whereas the release configuration uses 0.30 and its stock route can use uniform weights. These differences remain unresolved. Partial pretraining does not supply ancestry accuracy.

Assess sensitivity to the AncestralPaths sampling deficit, ARGMix reference restriction and ARGformer objective differences where conclusions depend on them.}

\section{Additional Scientific Results}
\subsection{Limited Matched Tests of Additional Context}
A matched test replaces the own node context in Equation~\ref{eq:local} with a span weighted average from the other trees in the same consecutive proper clade episode. For member $i$ of episode $E(i)$,
\begin{equation}
\bar h_{-i}=
\frac{\sum_{j\in E(i)}w_jh_j-w_ih_i}
{\sum_{j\in E(i)}w_j-w_i}.
\end{equation}
Only episodes with at least two trees are eligible. Replacing $V_lh_i$ with $V_l\bar h_{-i}$ leaves the parameter count, eligible nodes, initialization and added training budget unchanged. This comparison tests the value of information from other trees beyond an extra local transformation.

\subsection{Descriptive Application to Ancient Danish Genomes}
An earlier TreeLoom condition with context from other members of a clade episode was applied without further fitting to ten ancient Danish query individuals and eight proxy reference individuals from the imputed genomes analyzed by \citet{eurasians2024}. This is the episode condition in Table~\ref{tab:episode}, not the final model with sample memory. Five earlier individuals date to 5.44--5.67\,ka cal BP and five later individuals to 3.97--4.26\,ka cal BP. Three fixed 10\,Mb windows on chromosomes 20--22 contain 1,158 inferred trees and 8,587 qualified site records.

Assignments weighted equally across people integrated over physical span are 14.27 percentage points higher for EHG and 5.52 points higher for CHG in the later group. EHG has a positive contrast on each chromosome. CHG depends on chromosome 21 and changes to $-0.68$ points when it is omitted. Separate genotype affinity contrasts from the same imputation resource do not support the registered directions. There is no local ancestry truth or calibration of the model's outputs as mixture fractions. These descriptive predictions therefore illustrate application to empirical genealogies and do not validate the historical interpretation.
