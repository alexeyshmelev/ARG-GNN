\subsection{County Forecasting with the Adapted Core}
\label{app:countyforecasting}
TreeLoom's adapted GNN, county memory and recurrent core forecast UCI Hungarian Chickenpox Cases\footnote{\url{https://doi.org/10.24432/C5103B}.}. Two graph passes share weights. Six fits of 40 epochs each use three initialization seeds per arm, totaling 4,800 updates. Evaluation covers 20 counties and 79 test weeks, using 52 observed weeks per forecast and validation MAE selection before TEST.

Memory fails the prespecified 2\% MAE and paired uncertainty criteria despite lower RMSE (Table~\ref{tab:countyforecasting}). Paired Full-minus-NoMem MAE is $+0.260$ cases, with conditional 95\% interval $[0.105,0.427]$ from 10,000 circular resamples of 13 weeks. Shuffling the first 51 history weeks with the latest fixed raises both MAEs, supporting reliance on order only. Uncertainty is conditional on this one fixed county graph and series.
