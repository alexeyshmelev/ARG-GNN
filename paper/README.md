# Manuscript sources

`methods_working.tex` is an explicitly incomplete methods/protocol draft, not the final empirical paper. It contains the exact integral operator and its subdivision property, with no claimed neural performance gain or reviewer verdict. Architecture selection and final held-out studies are pending. The alternate semigroup candidate remains outside this draft until its scientific role is established.

The official AAAI-27 style and bibliography style beside the draft are byte-identical copies of the vendored assets. Working draft mode suppresses the submission copyright block. The final review bundle will use submission mode and the venue page limits. The editor/compilation constraint is server-only storage, so native Mac editor compilation is unavailable for this multi-file project.

Compile entirely on anogena with the project-local PDFTeX runtime. All output, caches and temporary files stay inside this repository. The final Overleaf bundle will include the completed manuscript, references, unchanged styles and used graphics.
