\caption{\textbf{(a,b)} Three intervals of an illustrative simulated ARG yield matching local trees. All sampled haplotypes supply observed alleles. References supply ancestry vectors, while query ancestry is unknown. Ancestors carry age $\tau$ and sampled/root indicators. \textbf{(c)} $N_t$ counts nodes, $S$ sampled haplotypes and $d$ feature width. Two GNN passes each traverse every node upward then downward and share weights. Node updates describe changes in descendant groups and each node's state. Sample memory follows persistent sampled identities. In each direction, $\rho_t=\exp(-w_t/\lambda)$ retains history and $1-\rho_t$ weights current group context $f$. The two histories are averaged. Their current group mean $\mu$ is centered by subtracting $f$, linearly projected and injected before the second GNN pass. All $S$ sampled embeddings remain aligned. $e_{tq}$ embeds haplotype $q$ in tree $t$. Magenta follows $q_1$. \textbf{(d)} One shared BiGRU with one layer processes each sampled sequence using logarithms of $1+w_t$ and $1+\Delta c_t^{\pm}$. These encode span and distances to neighboring interval centers. $\Vert$ concatenates local and recurrent embeddings. The MLP and softmax give ancestry probabilities $p_{tq}$, and argmax gives one ancestry call per interval. Feature values and predictions are schematic.}
