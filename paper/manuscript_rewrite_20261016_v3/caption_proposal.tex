\caption{Three slices of a small simulated ARG define the corresponding local trees. Diamonds mark recombination nodes, and sample colors preserve the same haplotype identities. Observed allele vectors are available for references and queries. Ancestry badges label the references, while query ancestry is unknown. Two reference examples and four output ancestry classes are drawn. Two complete graph traversals share parameters, each passing messages upward and then downward through every node. Local structural conditioning and a separate memory carried for the same sampled haplotype across trees modify inputs to the second traversal. Its output retains one embedding per sampled haplotype. A separate bidirectional GRU with one layer reads these aligned embeddings along the genome with interval spans and neighboring distances. The classifier combines local and recurrent context to produce ancestry probabilities and interval calls. $N_t$ is the number of nodes, $S$ the number of sampled haplotypes and $d$ the embedding width. Outputs are schematic.}
